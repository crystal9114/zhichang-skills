## 怎么装

把要用的目录整个拷进你的 Agent 的技能目录即可。以 Claude Code 为例：

```bash
git clone https://github.com/crystal9114/zhichang-skills.git
cp -r zhichang-skills/skills/gongzi-geshui-free ~/.claude/skills/
```

其他支持 Skill 的 Agent 照它自己的技能目录放。需要 Python 3.9 以上，脚本只用标准库。
