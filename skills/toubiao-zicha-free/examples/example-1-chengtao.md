# 样例 1：成套摘录 → 结论 + 偏离表

材料是虚构的（不是评测题），回答按本技能的做法先跑 `scripts/checks.py` 再出表，命令输出是真跑的。

## 用户输入

```text
依法必须招标的房建施工项目，纸质标，投标截止2026年12月8日9:00。帮我对一遍。
【招标文件】
[P3 须知前附表] 投标有效期：100日。投标保证金：叁万元，以现金或支票形式提交的须从投标人基本账户转出，截止时间前到账。
[P5 须知前附表] 最高投标限价：450万元，投标报价高于最高投标限价的，否决其投标。
[P9 资格要求] 具备有效的安全生产许可证。
【投标文件】
[P1 投标函] 投标有效期100日。投标总价：肆佰伍拾叁万元整（¥4,530,000）。法定代表人签字、单位章齐全。
[P3 授权委托书] 委托期限：自签署之日起至2027年2月28日。
[P12 保证金回单] 付款账户：基本存款账户，金额30000元，到账时间2026-12-05。
[P20 安全生产许可证] 有效期至2027年6月30日。
```

## 先跑的命令和输出

```
$ python3 scripts/checks.py validity --required 100 --promised 100 --source 投标函
满足：投标函写的 100 天 ≥ 要求 100 天
$ python3 scripts/checks.py cap --bid 4530000 --cap 450万
不满足：报价 4,530,000.00 元 超过限价/预算 4,500,000.00 元，超出 30,000.00 元，风险致命，超限价直接投标无效/否决
$ python3 scripts/checks.py amount --upper 肆佰伍拾叁万元整 --lower 4530000
满足：大写 4,530,000.00 元 = 小写 4,530,000.00 元
$ python3 scripts/checks.py cover --deadline 2026-12-08 --days 100 --until 2027-02-28 --what 授权委托书
不满足：授权委托书到 2027-02-28，早于投标有效期届满日，差 18 天；届满日 = 截止日 2026-12-08 + 100 天 = 2027-03-18（截止当天算第 1 天的口径是 2027-03-17）；风险高；改法：把委托期限改到 2027-03-18 或之后，或写「至投标有效期届满之日止」。招标文件对授权期限有单独写法的，以招标文件对授权期限的要求为准
$ python3 scripts/checks.py deposit --required 3万 --paid 30000
满足：提交 30,000.00 元 ≥ 要求 30,000.00 元
$ python3 scripts/checks.py cert --deadline 2026-12-08 --until 2027-06-30 --what 安全生产许可证
满足：安全生产许可证到 2027-06-30，截止日 2026-12-08 有效
```

## 技能回答

**项目回显**：依法招标房建施工｜纸质标｜截止 2026-12-08 09:00｜投标有效期 100 日｜投标保证金 3 万元，基本户转出、截止前到账｜最高投标限价 450 万元

**结论**：致命 1 条、高 1 条、中 0 条、低 0 条。交标前最先改的：①报价 453 万元超过最高投标限价 3 万元，降到 450 万元以内，开标一览表、明细表、大小写一起改；②授权委托书期限改到 2027-03-18 之后或写「至投标有效期届满之日止」。
