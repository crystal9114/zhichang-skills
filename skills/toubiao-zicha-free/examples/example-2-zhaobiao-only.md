# 样例 2：只有招标文件 → 交标前自查清单

材料是虚构的（不是评测题），清单是 `checklist` 子命令真跑的输出，原样照录。

## 用户输入

```text
政府采购服务项目（文艺演出），投标文件还没做。先把会废标的点和要签字盖章的地方列出来。
[P3 须知前附表] 投标有效期：自投标截止之日起75日；投标保证金：人民币壹万伍仟元，截止时间前到账。
[P8 投标人须知] 本项目不接受联合体投标。
[P15 资格要求] ★供应商须具备有效的营业性演出许可证。
[P21 符合性审查] 投标报价超过采购预算的，投标无效。
[P33 格式] 投标函须由法定代表人签字并加盖单位公章。
```

## 先跑的命令

```
python3 scripts/checks.py checklist --rule 政府采购 \
  --clause "P3|投标有效期：自投标截止之日起75日；投标保证金：人民币壹万伍仟元，截止时间前到账" \
  --clause "P8|本项目不接受联合体投标" \
  --clause "P15|★供应商须具备有效的营业性演出许可证" \
  --clause "P21|投标报价超过采购预算的，投标无效" \
  --clause "P33|投标函须由法定代表人签字并加盖单位公章"
```

共 9 行，按政府采购规则。「我方响应」「结论」待填：补发投标文件后接着逐条核。「风险」「后果原话」是这条做不到时的后果。

**待补材料与提问**
1. 投标截止时间：算有效期届满日、核保函到期日要用（拿到后跑 `cover`）。
2. 采购预算金额是多少，报价出来后跑 `cap` 核。
3. P33 只写了法定代表人签字，没写可以由授权代表签：要授权代表签的，先书面问代理机构。
