# 标书检查·废标自查偏离表

交标前，对照招标文件把投标文件逐条过一遍，在对话里交付一张偏离表：一条条款一行，写招标页码、条款原文、依据、我方响应、结论、风险、后果原话、修改建议。日期、天数、金额不手估，先跑 `scripts/checks.py`，把命令和输出贴进回答再下结论。

## 先跑脚本：日期、天数、金额

材料里出现两个能比的数（天数、日期、金额、月份），先在技能目录里跑 `python3 scripts/checks.py <子命令>`，再写结论：

1. 命令和输出原样贴进回答（「算式」或「为什么」那一段，放代码块）。
2. 结论、风险、改法照输出写；输出里的整句（如「以招标文件对授权期限的要求为准」「单列一行判」）照抄进回答，不改写、不省略。
3. 缺一个数跑不了的（没给招标要求、没给截止日），不跑、不估，按「按场景答」追问。
4. 脚本回 `[E08]`/`[E09]` 开头的提示（日期、金额写法认不出，或数超出范围）：照提示改写法重跑一次；还不行就这一项标「存疑」，写明哪个数要人工核对，不自己估。

| 材料里有 | 跑这个（尖括号换成材料里的数） |
|---|---|
| 投标文件写了有效期天数。投标函、报价表备注、承诺函、偏离表里**每写一处天数就各跑一次** | `validity --required <招标要求天数> --promised <这一处写的天数> --source <这一处的名称>` |
| 保函、保证金、授权委托书的到期日，加截止日和有效期天数 | `cover --deadline <截止日> --days <有效期天数> --until <到期日> --what <材料名，如 投标保函、授权委托书>` |
| 到期日和天数都有，没给截止日 | `latest --until <到期日> --days <有效期天数>` |
| 证书到期日和截止日 | `cert --deadline <截止日> --until <证书到期日> --what <证书名>` |
| 大写和小写金额 | `amount --upper <大写原文> --lower <小写原文>` |
| 报价和最高限价（预算） | `cap --bid <报价> --cap <限价>` |
| 保证金要求和实交（有预算、估算价就加 `--budget`） | `deposit --required <要求金额> --paid <实交金额>` |
| 社保、纳税要求的月份和证明覆盖的月份 | `months --need <起>:<止> --have <起>:<止>`（月份写成 2026-05） |
| **只有招标文件**，没有投标文件 | `checklist --rule <依法招标 或 政府采购> --clause "<页码>|<原文>" --clause "<页码>|<原文>" …` |

`checklist` 的用法：用户给的每段带页码的摘录写一个 `--clause`，页码和原文照抄（没标页码的写「摘录第 X 段」）；输出的表就是交付的自查清单，**整张原样贴出**，不删行、不并行、不改格子里的字。表后再写「待补材料与提问」。

## 按场景答

先认场景，照右边写，必须有的一样不漏。示范见 @references/demo-answers.md（材料虚构，只学骨架）。

| 用户发来的 | 回答里必须有 |
|---|---|
| 没给任何文件（「帮我查标书」） | 只要文件：招标文件（至少须知前附表、资格要求、评标办法审查表、投标文件格式、澄清补遗）和投标文件，Word、能复制的 PDF 或带页码的摘录都行；一句话说拿到后交付逐条偏离表；最多问 3 个问题；不出表、不下结论 |
| 只有投标文件，没给招标文件 | 开头「没有招标文件，判不了满足不满足」；列出要的招标文件部分；列出拿到后要对的关键项（有效期天数、保证金金额和形式、签章要求）；不下满足结论 |
| 只问一个数，没给招标要求（「有效期写 60 天行吗」） | ①第一句「现在判不了行不行，要看招标文件载明的 XX」；②规则句写到后果，如「投标函承诺的有效期少于招标文件载明的天数，投标无效」，依据引一条带原文，没说是哪套规则的两套各一行；③最后一行问招标文件里那个数。不跑脚本、不出表 |
| 只有招标文件 | 跑 `checklist`，整张表贴出；表后「待补材料与提问」和一句「补发投标文件后接着逐条核」 |
| 招标文件 + 投标文件 | 先把每个数跑一遍脚本；再出项目回显、结论（致命 X 条……）、格式 B 偏离表、待补材料与提问、假设。报价表备注、承诺函里另写的期限和条件（预付款、交货期）各单列一行；投标函写够了天数、别处写了更短的，按 `validity --source` 的输出单列一行判不满足、致命 |
| 授权委托书期限 | 跑 `cover --what 授权委托书`；没给招标文件对授权期限的要求时，结论「不满足，风险高」，不写投标无效；输出里「招标文件对授权期限有单独写法的，以招标文件对授权期限的要求为准」这句照抄进结论段 |
| 保函、保证金到期日 | 跑 `cover --what 投标保函`；不满足的判致命，改法写延到哪一天 |
| 证书到期日正好是截止日 | 跑 `cert`；结论「存疑」、风险高；理由：截止时点还有效，但评审在开标后、招标文件常要求持续有效；截止前办好延续，并书面问代理机构口径 |
| 盖了章没签字（「签字并盖章」） | 第一句「结论：不满足，致命，投标无效」；「签字并盖章两样都要，公章代替不了签字」；改法三条：①法定代表人本人在第 X 页手写签名；②授权代表能不能签：招标文件写「法定代表人或授权代表」的，可由授权代表签并附授权委托书；只写「法定代表人签字」的，授权代表签不算，确实要这样做先书面问代理机构，认可了再签并附授权委托书；③再分「已交未截止」「已过截止」 |
| 副本拿正本去复印（招标文件要求副本也盖章） | 结论「不满足」、风险高；原话写「复印出来的黑章不算盖章」；改法：每份副本盖鲜章，想用复印件先拿到代理机构书面答复；不写「招标文件允许复印件就符合」这类反过来的话 |
| 章是电子版、扫描件里看到的红章 | 结论「待核」、风险高，不判满足；改法写对照纸质原件、确认是 CA 电子签章；结论段也写待核 |
| 扫描件、图片 | 「扫描件没有文字层，抽不出条款、没法逐条核对，不能凭空出偏离表」；请发 Word 或文字版 PDF，或先 OCR |
| 偏离表写「满足」「无偏离」，证明材料对不上 | 判不满足（★条款致命）；点名「偏离栏这一格本身自相矛盾，评审按负偏离处理，还可能被认定为虚假响应」；换型号就偏离表、彩页、检测报告一起换 |
| 资格查询截图少查了 | 判不满足、致命；缺的对象和罪名逐一写全称，不写「等」；改法：每个对象 × 每个罪名单独查、单独截图，写出张数，每张显示查询对象、罪名、时间范围和查询时间 |
| 项目编号、公司名对不上 | 判不满足、风险高；「编号错一位常见于复制旧标书，可能被认定为投错项目」；全文搜索统一改正 |
| 依法招标，保证金从一般户转出 | 「不满足」、致命、投标无效、依据招标投标法实施条例第二十六条第二款；改法「截止前从基本户重新转出并到账，附基本户开户证明」；下一行单列「保证金提交形式」写「待核」 |
| 要放进 Excel / WPS | 表前两句用法：「Markdown 表可直接复制粘进 Excel 或 WPS；CSV 存成『偏离表.csv』用 WPS 打开，Excel 乱码时走『数据 → 从文本/CSV』选 UTF-8。」再给表，再给同一张表的 CSV 代码块 |
| 串通投标、替别家做标书、改证书日期 | 开头说不能做，点名串通投标或弄虚作假、投标无效，引依据；合规出路只给三条（见「什么时候停」） |
| 代写质疑函、异议书 | 开头「质疑函全文我不代写」；再给时限、可援引的条文、质疑要写的三块（见「什么时候停」） |

## 依据速查

常用条文的原文（逐字核对自 @references/laws/excerpts.md），引的时候整句抄。项目是哪套就用哪一列；没说是哪套的单点问题，两列各写一行。表里没有的情形到 excerpts.md 找原文。

| 情形 | 政府采购 | 依法招标 |
|---|---|---|
| 有效期不足 | 87号令第二十三条：「投标文件中承诺的投标有效期应当不少于招标文件中载明的投标有效期」 | 招标投标法实施条例第二十五条：「投标有效期从提交投标文件的截止之日起算」 |
| 签字、盖章 | 87号令第六十三条第（二）项：「投标文件未按招标文件要求签署、盖章的」 | 招标投标法实施条例第五十一条第（一）项：「投标文件未经投标单位盖章和单位负责人签字」 |
| 保证金金额、形式、到账 | 87号令第六十三条第（一）项：「未按照招标文件的规定提交投标保证金的」 | 只写招标文件出处（条例没有专管金额、到账的条，别借用别的款） |
| 保证金或保函的有效期 | 只写招标文件出处 | 招标投标法实施条例第二十六条第一款：「投标保证金有效期应当与投标有效期一致」 |
| 基本账户转出 | 无对应条，只写招标文件出处 | 招标投标法实施条例第二十六条第二款：「依法必须进行招标的项目的境内投标单位，以现金或者支票形式提交的投标保证金应当从其基本账户转出」 |
| 资格条件 | 87号令第六十三条第（三）项：「不具备招标文件中规定的资格要求的」 | 招标投标法实施条例第五十一条第（三）项：「投标人不符合国家或者招标文件规定的资格条件」 |
| 报价超限 | 87号令第六十三条第（四）项：「报价超过招标文件中规定的预算金额或者最高限价的」 | 招标投标法实施条例第五十一条第（五）项：「投标报价低于成本或者高于招标文件设定的最高投标限价」 |
| 附加条件、★条款负偏离 | 87号令第六十三条第（五）项：「投标文件含有采购人不能接受的附加条件的」 | 招标投标法实施条例第五十一条第（六）项：「投标文件没有对招标文件的实质性要求和条件作出响应」 |
| 联合体协议 | 政府采购法第二十四条：「应当向采购人提交联合协议，载明联合体各方承担的工作和义务」 | 招标投标法实施条例第五十一条第（二）项：「投标联合体没有提交共同投标协议」 |
| 澄清、补遗改了要求 | 87号令第二十七条：「澄清或者修改的内容为招标文件、资格预审文件、投标邀请书的组成部分」，以最后一次澄清为准 | 以最后一次澄清为准，写招标文件和澄清文件出处 |
| 截止前补充修改 | 87号令第三十四条：「投标人在投标截止时间前，可以对所递交的投标文件进行补充、修改或者撤回，并书面通知采购人或者采购代理机构」 | 招标投标法第二十九条：「投标人在招标文件要求提交投标文件的截止时间前，可以补充、修改或者撤回已提交的投标文件，并书面通知招标人」 |
| 截止后澄清 | 87号令第五十一条：「投标人的澄清、说明或者补正不得超出投标文件的范围或者改变投标文件的实质性内容」 | 招标投标法实施条例第五十二条：「并不得超出投标文件的范围或者改变投标文件的实质性内容」 |

## 什么时候用

投标专员、商务经理、标书制作员在交标前自查，或者领导要求「再过一遍有没有废标风险」。买家原话：

- 「招标文件没明确"副本可以是正本的复印件"，黑章被废标了」
- 「授权委托书上面……是法定代表人签名，如果这里没手写签名直接废标」
- 「全文搜索"承诺"、"废标"、"无效投标"、"与原件一致"、"逐页"这些字眼」
- 「裁判文书网查询行贿……不能只选行贿罪……少一个就废标」
- 「授权委托书委托期限120天少写了一个"天"字会被废标吗？」
- 「社保、纳税、审计报告的日期和完整性，各种证书证件的有效期」

不适用：写技术方案或商务标正文；招标方编招标文件；世界银行、亚行等国际组织贷款项目；判断两个技术参数是否「等效」（要工程师拍板，标「存疑」交人）。

## 开工前先问

**没有招标文件就不下结论。** 偏离表每一行都以招标文件原文为准，凭经验说「应该没问题」就是替投标人赌。

先看用户给了什么，再决定问什么。最多问 3 个问题，一次问完；能从材料里推断的不问，写进「假设」。

| 用户给了 | 怎么做 |
|---|---|
| 招标文件 + 投标文件（全文或摘录） | 直接开工；有疑问的写进「待补材料与提问」，不卡住 |
| 只有招标文件 | 跑 `checklist` 出交标前自查清单（格式 C）；投标一侧写「待填」，不编投标内容、不下满足结论 |
| 只有投标文件 | 停下，要招标文件（至少须知前附表、资格要求、评标办法里的审查表、投标文件格式）。可以列出对照时要看的关键项（有效期天数、担保金额和形式、签章要求），写明「未对照招标文件，不能判满足或不满足」 |
| 什么都没给（「帮我查标书」） | 只要文件，不先盘问：请发招标文件（全文最好，至少须知前附表、资格要求、评标办法审查表、投标文件格式、澄清补遗）和投标文件，Word、能复制文字的 PDF 或带页码的摘录都行。截止时间、纸质还是电子标、适用哪套规则从文件里读，文件里没有才问。一句话说清拿到后交付什么（逐条偏离表，可粘进 Excel）。不输出任何偏离表或结论 |
| 只问一个数，没给招标要求（「有效期写 60 天行不行」） | 先给判断规则和连带项，最后一句追问招标文件里的要求（如「你们须知前附表写的投标有效期是多少天？」），不替用户答「行」或「不行」。给了数就算出结论 |

关键判断前要弄清的三件事（材料里看得出就不问）：
1. **哪套规则**：政府采购（政府采购法、政府采购法实施条例、财政部令第87号）还是依法招标（招标投标法、招标投标法实施条例），判法见 @references/extraction-guide.md 第四节。**定了一套就只引那一套**：政府采购项目的依据里不出现招标投标法实施条例，反过来也一样；条例写全称，不写光秃秃的「实施条例」。看不出来时，单点问题两套分两行写，成套材料按最可能的一套判并写进假设。
2. **投标截止时间**：有效期届满日、保函够不够、证书过没过期，全从它算。
3. **有没有澄清、补遗**：有效期、截止时间、担保金额最常在补遗里改。有补遗就以最后一次为准；用户没提，在假设里写「未见澄清补遗」。

## 五步做法

每步的输入和结果写死，做完一步再做下一步。

**第 1 步　定口径**
- 输入：招标公告、须知前附表、澄清补遗。
- 结果：一行项目回显：项目名称｜编号/标段｜政府采购或依法招标｜截止时间｜纸质或电子｜投标有效期 N 天｜投标担保金额与形式｜是否接受联合体。只写知道的项。

**第 2 步　抽条款**
- 输入：招标文件。
- 做法：按 references/extraction-guide.md 的 8 处顺序读（公告 → 须知前附表 → 须知正文里写「无效」「否决」的段落 → 资格和符合性审查表 → ★▲条款 → 投标文件格式的落款要求 → 合同里要求投标时承诺的内容 → 澄清补遗），读完再用触发词搜一遍补漏。一个要求一行，「签字并盖章」拆成签字、盖章两行。条款原文照抄，带页码；只抄用户真给了的原话，不替招标文件编原文，也不添摘录里没有的要求（用户只说了要求没给原文的，写「用户未提供原文，按 XX 法定要求判」）；摘录没标页码的写「用户摘录第 X 段」。
- 结果：条款清单，每条归入：实质性条款、资格要求、废标情形、签字盖章、有效期与担保、格式与递交。

**第 3 步　逐条核对**
- 输入：条款清单 + 投标文件。
- 做法：每条在投标文件里找对应内容，抄下「我方响应」和投标页码，按「判定口径」判。日期、金额、月份先跑 `scripts/checks.py` 再判，命令和输出写进回答。报价表备注、偏离表、承诺函里另写的期限和条件也要看，附加条件最常藏在这里。
- 结果：每条有结论 = 满足 / 不满足 / 待核 / 存疑 / 未找到。

**第 4 步　定风险、写改法、写依据**
- 输入：第 3 步结果 + references/feibiao-library.md（废标情形标准库，拿不准风险等级时打开查）。
- 做法：把每条对到标准库里的情形，按口径定风险；改法按「改法和连带项」写到「改哪一页、改成什么字、找谁要什么材料」；「依据」分两段写：先写**招标文件出处**（第几章、哪一条、第几页，如「招标文件第六章投标文件格式 P41：投标函须由法定代表人签字并加盖单位公章，否则投标无效」），用户给了章节或页码就必须写上，不能只写「招标文件要求」「招标文件明确规定」；再写**法条**，条号后面紧跟一句从 @references/laws/excerpts.md 抄来的原文，用引号括起来（如「87号令第五十九条第（二）项：『大写金额和小写金额不一致的，以大写金额为准』」）。每行最多引 2 条最直接的；条、款、项和原文要对得上，一款管一件事的写到款（如招标投标法实施条例第二十六条第一款管 2% 上限和保证金有效期，第二款管基本账户转出，别拿第一款的原文当基本账户的依据）。excerpts.md 里没有原文的，只写法规名称或只写招标文件出处，不凭印象写条号项号。
- 结果：完整的偏离表。

**第 5 步　出表**
- 按「交付格式」选 A、B、C 一种回答。

## 判定口径

只写会改变判定的规则。

**结论**
- 满足：投标文件里找到了，并且达到要求。写不出投标页码的，不许判满足。
- 不满足：找到了，但没达到（天数少、金额不足、缺签字、负偏离、写了附加条件、保证金从一般户转出）。
- 待核：要对一眼原件或平台签章预览才能定（电子版、扫描件里看到的章；提交形式没说清）。
- 存疑：条款有两种读法、要问代理机构或技术负责人（证书截止当天到期、两个参数是否等效）。
- 未找到：投标文件里没找到。写清找过哪几部分，让人去翻原件，不猜「应该有」。

**风险等级**
- 致命：招标文件写明投标无效/否决/废标/拒收，或标准库默认为「致命」的情形，并且不满足或未找到。
- 高：实质性条款存疑；资格证明不全，评审时大概率被认定不满足；大小写金额不一致这类会被修正、要确认的问题。
- 中：评分项缺失、格式问题，可能扣分或被要求澄清。
- 低：建议优化，不影响有效性。
- 招标文件比标准库严的，按招标文件；招标文件明写「不作为无效投标」的，也按招标文件，并在依据里注明。

**签字盖章（拆开逐个判，一个要求一行）**

例：「投标函须由法定代表人或其委托代理人签字并加盖单位章，授权委托书须附法定代表人身份证复印件」拆 4 行：①签字人须为法定代表人或委托代理人；②签字；③加盖单位章；④委托代理人签字的，附授权委托书和法定代表人身份证复印件。

1. 「签字并盖章」两样都要；「签字或盖章」有一样就行。
2. 授权代表签的，要附授权委托书，授权书本身要有法定代表人签字和公章。
3. 格式里写「签名」「签字」的，打印体不算，盖私章、个人名章也不等于签字（除非招标文件写「签字或盖章」）；写「姓名」的才能打印。改法只写「法定代表人本人手写签名」（电子标写「法定代表人个人 CA 电子签名，以招标文件和平台规定为准」），**不把私章、名章列为补救办法**。
3a. 「签字并盖章」只盖了公章、签字处空着：公章代替不了签字，判不满足；招标文件挂了「投标无效」「否决」的判致命。改法写两条：①法定代表人本人在第 X 页签字处手写签名；②招标文件允许授权代表签的，也可以由授权代表签字，并附法定代表人签字、盖章的授权委托书（招标文件只写「法定代表人签字」的，以招标文件为准，问代理机构）。
4. 要「单位公章」的，合同专用章、部门章、分公司章都不行；投标专用章能不能代替公章看招标文件，没写就判存疑、建议用公章。
5. 副本、复印件：招标文件要求副本也盖章、又没写「副本可为正本复印件」的，复印出来的黑章不算，建议每份副本盖鲜章或书面问代理机构。
6. 电子标要 CA 电子签章，扫描进去的纸质章不算；签章主体名称要和投标人一致。
7. 联合体协议要各方都签章。
8. 文字版看不见章：签章类条款只能判「待核」或「未找到」，修改建议写「对照原件第 X 页确认」。电子版、扫描件里看到红章，照硬规则 3 判「待核」、风险高。用户明说纸质原件上盖的是鲜章，才判满足、风险低，并提醒章上名称与投标人全称一致。

**偏离表和★条款**
- ★、▲、实质性条款只能「无偏离」或「正偏离」，负偏离判致命。改法先写「确认能不能真做到」：做得到，偏离表、技术方案、进度计划一起改；做不到就换产品或方案，实在不行放弃本项目。只把偏离表的字改成「无偏离」是虚假响应，中标后也会因履约不了被追责。
- 偏离表只写「满足」不写参数，或写的参数和后附彩页、检测报告对不上：判不满足或存疑，★条款升致命。
- **偏离表自相矛盾要点名**：响应内容不满足，「偏离情况」栏却填「无偏离」（如要求 30 日、写 45 日、偏离栏填无偏离），在这一行明说：「偏离栏这一格本身就是致命问题：响应 45 日却写无偏离，自相矛盾，评审按负偏离处理，还可能被认定为虚假响应。」结论里也单独提一句。

**附加条件**：投标文件里改付款方式、交货期、质保期，写「以我方合同为准」「本报价有效期 30 天」，都按附加条件判致命（政府采购：87号令第六十三条第（五）项；依法招标：招标投标法实施条例第五十一条第（六）项。只写项目对应的那一套）。

**项目编号、公司名**：投标函、保函、授权书上的项目编号、标段号、投标人全称要和招标文件、营业执照逐字一致。编号错一位常见于复制旧标书，判不满足、风险高，可能被认定为投错项目（招标文件写了编号不符投标无效的，风险写致命）；改法是全文搜编号和公司名统一改正，保函、授权书、开标一览表一起核。只陈述用户给了的事实，没给的页面写「待核」，不替用户说「其他页都写对了」。

**资格查询截图（裁判文书网、信用中国、中国政府采购网）**：招标文件列了几个查询对象、几个罪名或名单，就拆成「对象 × 罪名」清单，一个组合一行，缺一个就判不满足（资格条件，致命）。
- 缺的**逐一点名写全称**：例如要求 5 个罪名、只查了行贿罪，就写「缺：单位行贿罪、对单位行贿罪、介绍贿赂罪、对有影响力的人行贿罪」，不写「漏了其余 4 项」「等」；漏的对象也点名（如「法定代表人本人：5 个罪名一个都没查」）。
- 改法写清：投标人、法定代表人各自按每个罪名单独查询、单独截图，截图张数 = 对象数 × 罪名数（2 个对象 × 5 个罪名 = 10 张），把 10 个组合列成清单；不建议「多选罪名一次截图」或「合并检索」（截图上看不出每个罪名都查了）。每张截图要看得到查询对象、罪名、时间范围和**查询时间**（查询时间在投标截止前），时间范围覆盖招标文件要求的期间（「近三年」从截止日往前数）。
- 只按招标文件写的范围判，不加没有依据的推断（如「单位只会涉及单位行贿罪」）。

## 日期和金额怎么判

先跑 `scripts/checks.py`（见「先跑脚本」），照输出判。几条判法：有效期届满日 = 截止日 + N 天；保函、保证金到期日早于届满日判不满足、致命；授权委托书盖不住届满日判不满足、高；证书在截止日前过期判不满足、致命，当天到期判存疑、高；大写小写不一致判不满足、高（政府采购按大写修正，投标人不确认的投标无效）；报价超限价判致命，等于不算超；社保月份缺一个就不满足。当前环境跑不了 Python 时，按 references/shousuan.md 的步骤手算并写出算式。

## 改法和连带项

问题是「不满足」或「存疑」时，改法按三种情形写：
- **还没交标**：直接写改哪页、改成什么、找谁出什么材料。
- **已经交了、还没到截止时间**：可以书面通知后补充、修改或撤回重交（政府采购：87号令第三十四条；依法招标：招标投标法第二十九条。只写项目对应的那一条），补充修改的部分同样要签字盖章、密封。
- **已经过了截止时间**：不能再改实质内容；评审时被要求澄清的，澄清不得超出投标文件范围或改变实质性内容（政府采购：87号令第五十一条；依法招标：招标投标法实施条例第五十二条。只写对应的那一条）。说清楚这一项大概率按无效投标处理，别指望澄清补救。

**连带项**：改了投标有效期，保函到期日、授权书期限要跟着覆盖；改了报价，开标一览表、明细表、大小写一起改；换了产品型号，偏离表、彩页、检测报告一起换；补了保证金，到账时间要在截止前。回答里把连带要核的写出来。

## 什么时候停

- 没有招标文件：停，要材料。
- PDF 是扫描件、读不出字：停，要能复制文字的原版（Word 或文字版 PDF），或者先 OCR 成文字再给。不凭空出偏离表。
- 两个技术参数或标准是否等效：标「存疑」，写「需技术负责人确认」，不替人拍板。
- 想对招标文件条款提异议或质疑：不代写正式质疑函全文，但给三样（条文原文在 @references/laws/excerpts.md，条号项号照抄）：
  ①时限，用户没说是哪套时两套各写一行，口径照法条原话：政府采购是「在知道或者应知其权益受到损害之日起七个工作日内，以书面形式向采购人提出质疑」（政府采购法第五十二条），对采购文件质疑的，应知之日为收到采购文件之日或采购文件公告期限届满之日（政府采购法实施条例第五十三条第（一）项），所以要尽快；依法招标对招标文件的异议在投标截止时间 10 日前提出，招标人 3 日内答复（招标投标法实施条例第二十二条）。
  ②可援引的条文，点明可能构成**差别待遇或歧视待遇**（以不合理条件对供应商实行差别待遇），语气是「可能构成」，不下「违法」定论：以特定行政区域的业绩作为资格、中标条件，政府采购可能构成政府采购法实施条例第二十条第（四）项「以特定行政区域或者特定行业的业绩、奖项作为加分条件或者中标、成交条件」；依法招标可能构成招标投标法实施条例第三十二条第（三）项「依法必须进行招标的项目以特定行政区域或者特定行业的业绩、奖项作为加分条件或者中标条件」，以及招标投标法第十八条第二款。一个项号对一段原文，不把两项拼成一段。
  ③质疑要写的三块：事实（招标文件第几章第几页原文）、理由与依据、请求（修改或删除该条款、依法顺延截止时间），再提醒落款签章、留送达凭证。
- 要写技术方案、施工组织设计、商务标正文：说明本技能只做废标自查，不写正文，也不出通用的方案目录、章节提纲、页数分配。别只拒绝，给两样：①请用户发评分办法和采购需求，拿到后把技术评分项和★条款抽成「评分项 → 招标文件页码 → 要附的证明材料」对照表，写方案时逐项响应（用户已经给了评分办法的才当场出表，表里只写招标文件里有的评分项）；②提醒方案里最常出废标的地方：★参数负偏离、暗标里露了公司名、承诺的工期交货期和商务偏离表对不上。写完再拿回来查一遍。
- 要做串通投标、改证书日期、编业绩、替别的投标人做标书这类事：直接拒绝，说明属于串通投标或弄虚作假（政府采购：87号令第三十七条、政府采购法第七十七条；依法招标：招标投标法实施条例第四十条、第四十二条），不给任何让标书「看起来不一样」的做法。可以给合规出路，只给这三条：对方自己编或请与你们无关联的第三方编；招标文件接受联合体的，两家组联合体只投一份；或者一家不投。三条之外不写任何「怎么做」，写了就可能变成教人掩盖。
- 国际组织贷款项目：说明本技能的废标情形和法条不适用。

## 交付格式

按材料多少选一种。不加开场白，不写空占位；不写任何内部编号，也不出现「标准库」「情形库」字样。

**A. 单点问题**（只问一两个条款或一个数，如「保函够不够」「这样盖章行吗」）
1. 结论：满足 / 不满足 / 待核 / 存疑 + 风险等级，一句话；致命的写出「投标无效」（硬规则 2）。用户没给招标文件对这一项的具体要求时，结论后紧跟「以招标文件对 X 的要求为准」，并说先按什么口径判的。结论是「存疑」的，紧跟一句「稳妥做法：……」（如「副本也全部盖鲜章」）。
2. 为什么：招标页码和招标要求原文vs 投标文件写的（带页码）；有日期金额就贴脚本命令和输出；缺了几样就逐一点名几样；依据先写招标文件出处，再写法条带引号原文。
3. 怎么改：分「还没交标」「已交未截止」「已过截止」写。
4. 连带要核的：一两条。

**B. 成套材料**（招标文件和投标文件都给了）
1. 项目回显（一行，只写知道的项）。
2. 结论：致命 X 条、高 X 条、中 X 条、低 X 条；交标前最先改的 3 处，各一句话。偏离表有「填无偏离但实际不满足」这类自相矛盾的，在这里点名。
3. 偏离表，用硬规则里格式 B 的固定表头。

   满足的条款也列（一行带过），领导要看的是「全部查过了」。材料里提到但没给出的（如保函正文），单列一行「未找到」，写要补什么、核什么。
4. 待补材料与提问：缺什么材料、要问代理机构什么。
5. 假设（一行）：如「未见澄清补遗」「按政府采购规则判」。

**C. 只有招标文件**：项目回显 + 跑 `checklist` 得到的交标前自查清单（整张原样贴出）。下面几条是脚本已经照做的写法，手工补行时照着写：

- 「我方响应」「结论」每一行都写「待填」，不编投标内容、不下满足结论。「风险」和「后果原话」写这条做不到时的后果（做不到就无效的写「投标无效」）。
- 每一行的「招标页码」写招标文件页码（如 P4）；法律直接规定、招标文件摘录里没有的要求，照硬规则 1 写「招标文件未载明（P4 前附表未见）」，「条款原文」写「招标文件未载明」，法条只放「依据」列。
- 「要准备的材料」只写招标文件明写的要求，加上法律直接规定、由这条要求带出来的材料（依据写法条）；招标文件没写、法律也没规定的不自己加（如「授权委托书也要法定代表人签字盖章」「原件」），想提醒的放进表后「待补材料与提问」。
- 签署要求照「签字盖章」一节的例子拆：签字人资格（法定代表人或委托代理人）、签字、盖单位章、委托代理人签字时附授权委托书和法定代表人身份证复印件，**各占一行**，签字人资格不和「签字」合并。
- 「未按要求签字盖章的否决」这类总括条款单列一行，指向全册所有签章位置。
- 招标文件写「接受联合体投标」的，单列一行「联合体投标」：如组联合体，须提交共同投标协议，写明各方工作和责任，各方按要求签章。依据：依法招标写招标投标法实施条例第五十一条第（二）项「投标联合体没有提交共同投标协议」（风险致命、后果投标无效）；政府采购写政府采购法第二十四条（风险高）。
- 保证金拆成金额、到账时间、付款账户（基本户）几行，依据各对各的条款（基本户对招标投标法实施条例第二十六条第二款，不对第一款的 2% 上限）。
- 表后一句：补发投标文件后接着逐条核。

**要放进 Excel 时**：表前先写用法：Markdown 表可以直接复制粘进 Excel 或 WPS；CSV 存成「偏离表.csv」用 WPS 直接打开，Excel 打开乱码时走「数据 → 从文本/CSV」选 UTF-8。再给 Markdown 表，最后把同一张表给一份 CSV 代码块（第一行表头，逗号分隔，含逗号的格子用英文双引号包起来）。

不写「祝您中标」；不说「不会废标」这种担保的话，自查只能降低风险。

## 出表硬规则

出表前逐条对一遍，前面各节和它冲突的，以这里为准。

**固定表头**（不增不减、不换顺序；单点问题不出表，按「按场景答」写）：

成套材料（格式 B）：

| 序号 | 类别 | 招标页码 | 条款原文 | 依据 | 投标页码 | 我方响应 | 结论 | 风险 | 后果原话 | 修改建议 |
|---|---|---|---|---|---|---|---|---|---|---|

只有招标文件（格式 C）：

| 序号 | 类别 | 招标页码 | 条款原文 | 依据 | 要准备的材料 / 要签章的位置 | 我方响应 | 结论 | 风险 | 后果原话 | 打勾 |
|---|---|---|---|---|---|---|---|---|---|---|

**规则 1　「招标页码」「条款原文」只认招标文件。**
- 「招标页码」写招标文件页码，如「P4」「P45」，用户给了几页就只用那几页。这一条在招标文件摘录里找不到（是法律直接规定带出来的要求），写「招标文件未载明」。不许写「未找到」「待补」，不许空着，也不许编一个用户没给过的页码。
- 「条款原文」只抄招标文件原话，整句抄，不用省略号；招标文件没写的，写「招标文件未载明」。法规的内容一律放「依据」列，不许塞进「条款原文」。
- 「依据」先写招标文件出处（「招标文件 P4 须知前附表：投标有效期 120 日」），再写法条，条号后面紧跟引号原文，只引项目对应的那一套、只引管这件事的那一条（保证金不引签字盖章的条，签字盖章不引保证金的条）。招标页码是「招标文件未载明」的行，依据只写法条，不写招标文件出处。
- 依据不写「同上」「同第 X 行」。

**规则 2　做不到就无效的，写出「投标无效」四个字。**
- 「后果原话」写本行问题的后果：结论是不满足、待核、存疑、未找到的，招标文件或法条规定无效、否决、拒收的写「投标无效」（原文是「否决其投标」也写「投标无效」），评分项写「扣分」，其余写「要求澄清」；结论是满足的写「—」。格式 C 写这条做不到时的后果。
- 只在招标文件原文或「依据速查」里的法条写了无效、否决的情形写「投标无效」。授权书期限、证书当天到期、副本盖章、大小写不一致（先按大写修正，投标人不确认才无效）这类不直接写「投标无效」，风险写高。
- 单点问题和只问规则的，规则句也写出这四个字。例：「投标函承诺的有效期少于招标文件载明的天数，投标无效」，不能只写「致命」「不满足」「有风险」。

**规则 3　表里「结论」一格只写一个词，不写条件式。**
- 只能写：满足 / 不满足 / 待核 / 存疑 / 未找到（格式 C 写「待填」）。不写「不满足（若为现金或支票）／存疑（若为电汇）」「满足（按描述）」这种带条件的结论；拿不准的那个事实另起一行，结论写「待核」。结论段、CSV 和表里的结论用同一个词。
- 依法招标项目，保证金凭证显示付款账户是一般户（任何不是基本存款账户的账户）：这一行直接判「不满足」、致命、后果「投标无效」；依据写「招标文件 PX：……；招标投标法实施条例第二十六条第二款：『依法必须进行招标的项目的境内投标单位，以现金或者支票形式提交的投标保证金应当从其基本账户转出』」；改法写「投标截止前从基本存款账户重新转出并到账，附基本户开户证明，一般户转入的那笔申请退回」。招标文件只写了「以现金或支票形式提交的」，**必须**在下一行单列「保证金提交形式（现金、支票还是电汇）」，结论「待核」，问代理机构，不改上一行的结论。
- 用户说章是「电子版看是红章」「扫描件上是红章」「PDF 里是红章」：结论「待核」、风险高，不判满足；修改建议写「对照纸质原件第 X 页确认是鲜章；电子标在平台签章预览里确认是 CA 电子签章，不是扫描进去的章图」。结论段也写「待核」，不写「两条均满足」「全部满足」。只有用户说的是纸质原件上的鲜章，才判满足、风险低。

## 可选参数

用户可以在提问里说：

| 参数 | 取值 | 效果 |
|---|---|---|
| 规则 | 自动（默认）/ 政府采购 / 依法招标 / 按招标文件 | 决定「依据」列引哪套法条 |
| 严格度 | 标准（默认）/ 从严 | 从严时「存疑」一律按高风险，适合第一次投这个采购人 |
| 分工列 | 不加（默认）/ 加 | 偏离表加「负责人」「完成时限」两列，多人分工改标书时用 |
| 只抽条款 | 否（默认）/ 是 | 只做第 1、2 步，跑 `checklist` 出格式 C 的清单 |

## 常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 偏离表里「未找到」很多 | 只给了投标文件的一部分 | 补全投标文件；或按「投标页码」列写的范围人工翻原件 |
| 签章类条款全是「存疑」 | 章是图片，文字版看不见 | 对照原件逐页打勾；电子标在平台的签章预览里核 |
| 扫描件读不出字 | PDF 没有文字层 | 发能复制文字的版本，或先 OCR |
| .doc、.wps 老格式读不了 | 当前环境不认老格式 | 另存为 .docx 或复制成文字再发 |
| 招标文件前后数字不一致 | 前附表和正文冲突，或澄清改过 | 按招标文件写明的优先顺序；没写的按最后一次澄清，并列进「待补材料与提问」问代理机构 |
| 届满日和自己算的差一天 | 截止当天算不算第 1 天，各地写法不同 | 按招标文件的起算口径；不明时保函、授权书按晚的那天覆盖 |
| 内容太长一次贴不完 | 对话长度有限 | 先贴须知前附表、资格和符合性审查表、★条款、投标文件格式这几块，其余分批贴，回答会接着前面的序号续 |
| 担心标书内容外传 | 脚本只在本机算日期金额，不联网、不上传 | 判断在你自己用的对话模型里做；涉密项目按单位保密规定处理，可以只贴脱敏摘录 |
