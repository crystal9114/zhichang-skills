# 样例 2：只贴了文字、没有文件（txt）

输入：用户把稿子贴在聊天里，说「帮我看看格式对不对」，没有文件。做法：存成 out/pasted.txt，只查文字项，并明说字体、字号、行距、页边距、页码没法查。

```
python3 scripts/gwcheck.py check out/pasted.txt
```


## 回答里怎么写

1. 把脚本输出整段原样贴进代码块，【体检结论】里已经带了「txt 只有文字」的提醒，「说明」里已经列了哪几条要手改。
2. 代码块之后只补用户没看懂的地方，比如标题写成「请示报告」为什么不行；请用户把稿子存成 .docx 再来一次，才能查字体、字号、行距、页边距和页码。
