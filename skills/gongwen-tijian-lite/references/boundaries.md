# 边界：什么不做，给什么方向

本技能只体检已经写好的稿子的格式和文字规范。下面这些不在范围里，说明原因并给下一步，不要硬做。

| 用户要的 | 不做的原因 | 给的方向 |
|---|---|---|
| 替我起草一份通知、请示、报告 | 本技能不写正文，也不改写内容 | 先把稿子写出来，写好后拿来体检；格式想一次到位，可以用 Word 里的国标公文模板，再来体检核对。用户明确问到有没有起草服务时，如实告知同店有按次收费的公文起草与排版版（gongwen-gb9704-word），由用户自己决定 |
| 改写、润色、精简我的正文 | 内容和措辞由用户负责，脚本不动文字 | 可以逐条指出文种、结语、序号、数字、标点上的规范问题，改写由用户或其他工具做 |
| 做带红头的文件、红色分隔线、套红 | 红色发文机关标志和分隔线要按本单位的红头模板制作，脚本只读不造 | 向本单位办公室要红头模板；体检时红头部分列入人工核对项，核对发文字号位置、分隔线颜色和长度（第 7.2.4、7.2.7 条） |
| 涉密文件 | 涉密文件的密级标注、保密期限和处理流程由保密部门管理，不应放进通用工具 | 在单位涉密设备和流程内处理；格式要求可参考国标第 7.2.2 条 |
| 解释党内法规条文、判断某条怎么适用 | 这是对条文含义的解释，不是格式体检 | 看《中国共产党党政机关公文处理工作条例》原文和本单位办公室的解释 |
| 判断文号、日期、机关名称、数字对不对 | 脚本只查写法，不能核实事实 | 对照原始材料、批件和台账逐项核实 |
| 单位有自己的版式规定，和国标不同 | 以单位规定为准 | 把单位规定里的页边距、字体等数值告诉我，体检时按单位的数值对照说明差异 |
| 检查 PDF、图片、扫描件的字体行距 | 这些文件没有可读的版式信息 | 转成 .docx 再检查，或把文字粘进 txt 只查文字项 |
| 联网查最新政策、查红头文件真伪 | 本技能全程离线 | 到政府官网或本单位办公系统核对 |

## 离线说明

脚本不联网、不注册、不上传，读文件、出清单、一键改都在本机完成。文件体检后留在本机，输出的清单也只写在本机。
