# 国标要点和文种对照

用自己的话整理 GB/T 9704-2012《党政机关公文格式》里体检用到的数值和写法。国家标准的公开要求可以照引，细节以标准正文为准。

## 页面

| 项目 | 要求 | 条款 |
|---|---|---|
| 纸张 | A4，210mm × 297mm，纵向 | 第 5.1 条 |
| 页边距 | 上（天头）37mm，下 35mm，左（订口）28mm，右 26mm，各允许 ±1mm | 第 5.2.1 条 |
| 版心 | 156mm × 225mm | 第 5.2.1 条 |
| 行数字数 | 每面 22 行，每行 28 字，撑满版心 | 第 5.2 条 |
| 文字颜色 | 无特殊说明一律黑色 | 第 5.2 条 |

常见换算：三号字 16 磅，二号字 22 磅，四号字 14 磅。225mm 除以 22 行约 28.95 磅，所以正文行距常设固定值 28 到 29 磅；Word 里每行 28 字要靠文档网格（指定行和字符网格）压出来，不设网格时三号字每行只排得下约 27 个。

## 各要素的字体和位置

| 要素 | 字体字号 | 位置和写法 | 条款 |
|---|---|---|---|
| 发文字号 | 三号仿宋 | 红色分隔线下空二行居中；机关代字、年份、序号，年份用六角括号〔〕，序号不加「第」、不编虚位（不写 01），后加「号」 | 第 7.2.5 条 |
| 标题 | 二号小标宋 | 居中，可分一行或多行，回行要词意完整、排列对称 | 第 7.3.1 条 |
| 主送机关 | 三号仿宋 | 标题下空一行，居左顶格，回行仍顶格，最后一个机关名称后用全角冒号 | 第 7.3.2 条 |
| 正文 | 三号仿宋 | 每个自然段左空二字，回行顶格 | 第 7.3.3 条 |
| 层次序号 | 三号 | 「一、」黑体；「（一）」楷体；「1.」仿宋；「（1）」仿宋 | 第 7.3.3 条 |
| 附件说明 | 三号仿宋 | 正文下空一行，左空二字写「附件」，后接全角冒号和名称；多个附件用阿拉伯数字标序号；名称后不加标点；回行与上一行名称首字对齐 | 第 7.3.4 条 |
| 署名、日期、印章 | 三号仿宋 | 加盖印章：署名以日期为准居中，印章端正居中下压署名和日期，顶端上距正文一行之内；不盖章：署名右空二字，日期在下一行，首字比署名首字右移二字 | 第 7.3.5 条 |
| 成文日期写法 | 阿拉伯数字 | 年月日标全，年份写全称，月日不编虚位：2026年3月5日 | 第 7.3.5 条 |
| 附注 | 三号仿宋 | 成文日期下一行，居左空二字，加圆括号 | 第 7.3.6 条 |
| 附件 | 「附件」及序号三号黑体 | 另面编排，顶格写在版心左上角第一行，标题居中在第三行 | 第 7.3.7 条 |
| 抄送机关 | 四号仿宋 | 印发机关上一行，左右各空一字；「抄送」后全角冒号；名称之间逗号，最后句号 | 第 7.4.2 条 |
| 印发机关和日期 | 四号仿宋 | 印发机关左空一字，日期右空一字，日期阿拉伯数字标全，后加「印发」 | 第 7.4.3 条 |
| 页码 | 四号半角宋体阿拉伯数字 | 版心下边缘之下，数字左右各一条一字线（形如：— 1 —），一字线上距版心 7mm；单页码居右空一字，双页码居左空一字；只有空白页和版记页可不编页码 | 第 7.5 条 |

上行文（请示、报告）发文字号居左空一字，与签发人姓名同一行；这种版式脚本只提示，不判错。

## 文种与结语对照

依据《党政机关公文处理工作条例》第八条（文种）和第十五条（上行文规则）。

| 文种 | 方向 | 常见结语 | 体检会查的错 |
|---|---|---|---|
| 通知、通报、决定、公告、通告 | 下行或周知 | 特此通知、特此通报 | 结语写成「妥否，请批示」「请审批」 |
| 请示 | 上行 | 妥否，请批示；请予批准 | 要有明确请求；原则上只主送一个上级；一文一事；不写「特此报告」 |
| 报告 | 上行 | 特此报告 | 报告里不得夹带请示事项（请批准、请批示） |
| 批复 | 下行 | 此复 | 不写请示用语 |
| 函 | 平行 | 请予研究函复；特此函告 | 无 |
| 请示报告 | 无此文种 | 无 | 标题不能合写，要请求批准就写请示，只汇报就写报告 |

## 数字和标点常见错（GB/T 15835-2011、GB/T 15834-2011）

| 错法 | 正确写法 |
|---|---|
| 全角数字 ３０ | 半角数字 30 |
| 3、4天 或 三、四天 | 三四天（相邻两数连用表概数，不加顿号） |
| 约200人左右 | 约200人，或 200人左右 |
| 3-5万元 | 3万～5万元，或 3万元至5万元 |
| 百分之二十（统计数据） | 20% |
| 二〇二六年（日期） | 2026年 |
| 2026.3.5、2026-03-05 | 2026年3月5日 |
| 2026 年 3 月 5 日 | 数字和年月日之间不留空格 |
| 直引号 " " | 弯引号 “ ” |
| 省略号 ... | …… |
| 单个破折号 | ——（占两个字位） |
| 中文句子里的半角逗号句号冒号括号 | 全角 ，。：（ ） |
