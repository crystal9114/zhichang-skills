# 脚本跑不了时的手算步骤

只在脚本报 E09、或环境里没有 Python 时用。回答里写明「以下为手算，请复核」。

1. 每月应纳税所得额增量 = 应发 − 免税收入 − 5000 − 三险个人 − 公积金个人（≤12% 部分）− 专项附加 − 其他扣除。
2. 第 n 个月累计应纳税所得额 = 前 n 个月增量相加（≤0 按 0）。年中入职从入职月数起；首次就业的第一个月减除费用是 5000 × 当月月份；适用 6 万标准的，减除费用全年固定 60000。
3. 累计应纳税额 = 累计应纳税所得额 × 税率 − 速算扣除数（年度表：36000 以内 3%/0；36000~144000 10%/2520；144000~300000 20%/16920；300000~420000 25%/31920；420000~660000 30%/52920；660000~960000 35%/85920；以上 45%/181920）。
4. 本月个税 = 累计应纳税额 − 前几个月已预扣合计（负数按 0）。
5. 到手 = 应发 − 三险个人 − 公积金个人 − 本月个税（发年终奖的月份再加奖金、减奖金税）。
6. 年终奖单独计税 = 奖金 × 税率 − 速算扣除数，税率按「奖金 ÷ 12」查月度表（3000 以内 3%/0；3000~12000 10%/210；12000~25000 20%/1410；25000~35000 25%/2660；35000~55000 30%/4410；55000~80000 35%/7160；以上 45%/15160），速算扣除数只减一次。
7. 并入综合所得：工资部分全年应纳税所得额 W 加上奖金，按年度表算一次；和「年度表(W) + 奖金单独计税的税」比，取小的。

手算最容易错的两处：跨 36000、144000 那个月只有超过部分按新税率（用累计公式算就不会错）；年终奖刚过 36000、144000 等临界点时税额跳一大截（临界区间见 tax-rules.md 第 2 节）。
