# 离职方式代码、特殊情形代码

`--reason` 写代码或中文别名都行；`--flags` 多个用逗号隔开。**离职方式没问清就写 `unknown`**：脚本只列四种情形的对比，不下结论。

## 离职方式（--reason）

| 代码 | 中文别名 | 情形 | 结果 |
|---|---|---|---|
| employer_negotiated | 协商-单位提出、单位协商、公司协商 | 单位提出、双方协商一致解除 | N |
| employee_negotiated | 协商-员工提出、员工协商 | 员工提出、双方协商一致解除 | 0 |
| objective | 第四十条、不能胜任、医疗期满、客观情况变化 | 单位依第四十条解除；配 `--notice 有/没有/未知` | N；没提前 30 天书面通知为 N+1 |
| layoff | 裁员、经济性裁员 | 经济性裁员（第四十一条） | N |
| contract_expired | 到期不续、合同到期 | 固定期限合同到期单位不续；单位维持或提高条件续签、员工不同意的加 `--renew-declined` | N 或 0 |
| employee_forced | 被迫离职、被迫解除 | 单位欠薪、不缴社保等，员工依第三十八条解除 | N |
| employee_resign | 主动辞职、辞职 | 员工主动辞职 | 0 |
| illegal_dismissal | 违法解除、违法辞退 | 用户已确认单位没有法定理由（如微信一句「明天别来了」、没给理由），或单位理由明显不成立 | 2N |
| misconduct | 违纪辞退、严重违纪 | 单位以严重违纪等第三十九条理由解除，员工不认 | 理由成立 0，不成立 2N；按 2N 列并标存疑 |
| probation_fail | 试用期不合格 | 单位以试用期不符合录用条件解除，员工不认 | 同上 |
| closure | 公司关闭、破产 | 单位破产、吊销、责令关闭、撤销、提前解散 | N |
| unknown | 未确认、不清楚 | 离职方式还没问清 | 只列对比，不下结论 |

**怎么选**：「公司让我走、给 N+1 让签协商」→ 单位提出的协商（employer_negotiated），N+1 里的 +1 是谈判价不是法定；「被逼写辞职信」→ 先问辞职信上写的理由，写个人原因的按 employee_resign 算并提示风险，写因欠薪、未缴社保的按 employee_forced；「调岗降薪不同意被开」→ 先问单位给的书面理由，不清楚就 unknown。

## 特殊情形（--flags）

| 代码 | 中文别名 | 脚本怎么处理 |
|---|---|---|
| work_injury | 工伤 | 停（E07），不出金额 |
| dispatch | 派遣、劳务派遣 | 停 |
| outsourcing | 外包、驻场 | 停：先分清和谁签的合同 |
| overseas | 境外、外派 | 停：本技能只按中国大陆劳动法算 |
| foreign | 外籍、港澳台 | 停 |
| retired | 退休、返聘 | 停：一般按劳务关系 |
| civil_servant | 编制、公务员 | 停 |
| group | 集体 | 停 |
| non_compete | 竞业、股权 | 停 |
| part_time | 非全日制、兼职 | 停 |
| criminal | 刑事、报警 | 停：刑事部分找刑辩律师 |
| pregnant | 孕期、怀孕、产期、哺乳期 | 照算；单位按第四十条、第四十一条解除或到期终止的转按 2N |
| medical_period | 医疗期 | 同上 |
| near_retire_15y | 老员工 | 连续工作满 15 年且离退休不足 5 年，同上 |
| transfer | 调岗、降薪、调岗降薪、穿小鞋、排挤 | 照算，不停；还没走、想知道走了能拿多少时用，脚本打出「自己辞职一般 0、第三十八条情形书面解除才有 N」的开头和调岗降薪、书面通知、欠薪、社保四个分开的问题 |
