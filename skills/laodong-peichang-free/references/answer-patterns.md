# 按场景怎么回（示范骨架）

所有场景都先跑脚本。回答骨架：**一句话结论 → 金额表（项目、金额、算式、依据）→ 时效 → 存疑和地方口径 → 还要问 / 下一步 → 附：跑的命令和输出**。下面只写每个场景和骨架不同的地方。

## A. 事实齐、离职方式清楚（最常见）

结论句直接给合计和定性依据，例如：「按你说的情况（微信通知明天别来、没给理由），如果单位拿不出合法解除的理由和证据，可以主张违法解除赔偿金 2N 共 180,000 元，不再另拿 N 和代通知金。」
- 「如果单位拿不出……」这个条件句不能省：是否违法解除由仲裁委认定，回答不替用户下定论。
- 下一步写三件：留证据（解除的聊天记录、工资流水、社保记录、劳动合同）、找单位要解除证明（第五十条）、向劳动合同履行地的仲裁委申请（不收费）。

## B. 离职方式没说清（「被公司开了」「让我走人」）

先跑 `check`，再用 `--reason unknown` 跑 `quick` 拿对比表。回答：
1. 第一句写「先确认是谁提出解除、单位给的理由」，列出 check 给的问题（最多 3 个，按顺序）。
2. 给对比表当区间：0 / N / N+1 / 2N 各多少，明确写「问清之前这不是结论」。
3. 不写「你这是违法解除」。

## C. 工资基数说不清（只说「月薪 8000」，有奖金、提成、年终奖）

- 有构成就用 `--parts`，年终奖自动 ÷12；只有一个数就用 `--wage`，回答里把脚本那条「只报了基本工资会少算」的存疑原样带上。
- 用户问「按税前还是税后」：按税前应发；「含不含加班费」：多数地方含、各地口径不一，以当地仲裁委为准。

## D. 高工资

带 `--city`。脚本会写「高于三倍封顶线 → 基数按封顶线、年限最多 12 年」，或「没超过 → 不封顶、也不受 12 年上限」。两种都要把这句写进回答，这是心算最常错的地方。表里没有的城市：请用户给当地人社局公布的上年度职工月平均工资，或写明「未做封顶判断」。

## E. 超过一年 / 快到一年

- 已过：结论写「本来能要 X 元，但已过一年仲裁时效」，紧接着问有没有时效中断的记录（书面催要、投诉、单位答应付钱），不要直接说「告不了了」；有中断证据的从中断那天重新算一年。
- 临近（30 天内）：第一句就提醒截止日，建议先去仲裁委递申请（仲裁申请书可以口头申请，由仲裁委记入笔录）。
- 二倍工资单独说两种起算口径。

## F. 材料不全（只给了一两个数）

不能只回一串问题。同时给：要补的问题（最多 3 个，带为什么）→ 每种离职方式怎么算的对照表 → 一个按假设跑出来的数（`--years 4`，「3 年多」写 `--years 3多`，`--reason unknown`，脚本会写出假设；有【回答开头照抄】【还要问（逐条照抄）】就照抄）并写「按假设估，不是结论」→ 现在能做的事（证据、解除证明、时效）。一点数都没给的（「被辞退了能赔多少」），可以用一个写明的示例（比如「举例：月薪 1 万、干满 3 年」）跑一次让用户看懂怎么算，同样标明是示例。

## G. 超出范围（脚本报 E07，或用户要找律师代理、刑事、派遣外包、境外用工）

派遣、外包、境外：脚本输出的【回答开头照抄】原样作第一段（不出确定金额、只给 N 到 2N 粗算区间、律师或仲裁委是首要下一步），【还要问（逐条照抄）】逐条问；不按普通辞退出 N/2N 结论表。不能一句「找律师」打发。顺序：为什么不能按普通辞退算 → 一般规则（向谁主张、按什么算）→ 先走什么程序、找谁（律师、当地劳动人事争议仲裁委员会窗口、12348 法律援助、劳动监察）→ 现在能做的准备 → 用户问能赔多少的，`--flags <情形> --rough` 跑粗算参考数，写明前提。
- **要律师代理、出庭**：明说不能当代理人；给可以委托的人（律师、基层法律服务工作者、工会推荐的人、近亲属、法律援助，要写授权委托书）、开庭准备（陈述提纲、证据目录、对方可能的说法和回应）；事实给了就把请求金额算好。
- **刑事**：不判断构不构成犯罪、判几年；可以讲法律框架（《中华人民共和国刑法》第二百七十六条之一：一般要先经有关部门责令支付、逾期仍不支付才追究，法定刑档见 references/laws.md，个案由法院认定），指向公安、劳动监察、刑辩律师；欠薪同时走仲裁或劳动监察。被报警又被开除的，劳动赔偿看解除理由是否成立（单位举证）。
- **派遣**：劳动合同在派遣单位；被退回无工作期间派遣单位按当地最低工资按月付报酬（第五十八条）；用工单位造成损害两家连带（第九十二条），两家都列为被申请人；派遣单位解除的按普通规则算 N 或 2N（可 `--rough` 粗算）。
- **外包、驻场**：先分清和谁签的劳动合同、谁发工资、谁交社保，一般向签合同的外包公司主张，不是向甲方。
- **境外用工**：国内公司外派的（合同在国内公司）一般可按中国法主张，境外公司直接雇佣的多按当地法；本技能只按中国大陆劳动法算，境外部分找涉外律师。

## H. HR 问「怎么辞退成本最低又合法」

照算 N / N+1 / 2N 对比，讲清每种要什么前提（第四十条要先调岗或培训、要提前 30 天书面通知或付代通知金；协商解除要书面协议；第四十二条保护的人不能按第四十条、第四十一条解除）。不教规避法律的做法（逼员工自离、不发工资逼走、倒签协议）。

## 用户主动问仲裁申请书、Excel 测算表

如实说：本技能只做速算和体检，不出 Word 申请书和 Excel 表；有同作者的收费版能出这两样文件。只在用户主动问时说，不主动推荐。仲裁申请书要写的内容可以按《中华人民共和国劳动争议调解仲裁法》第二十八条列给用户自己写。
