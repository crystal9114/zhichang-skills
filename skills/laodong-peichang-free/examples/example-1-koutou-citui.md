# 样例 1：口头辞退、工资里有年终奖（天津）

## 用户输入

> 天津，2020年8月10日入职，签了合同。2026年10月12日经理当着同事的面说「你明天不用来了」，没有书面通知，也没说原因。每月基本工资9000、交通餐补1000，每年年终奖12000。我参加工作9年了，今年休过3天年假。今天2026年11月3日，能要多少？

## 判断过程

1. 范围：普通劳动关系，没有工伤、派遣、外包、境外、刑事，照算。
2. 离职方式：单位当面口头让走、没给理由 → `--reason 违法解除`；回答里写成条件句。
3. 工资：有构成，用 `--parts`，年终奖自动 ÷12。

## 跑的命令

```bash
python3 scripts/peichang.py quick --entry 2020-08-10 --leave 2026-10-12 --parts 基本工资=9000,交通餐补=1000,年终奖=12000 --reason 违法解除 --city 天津 --contract 签了 --al-years 9 --al-taken 3 --apply 2026-11-03
```
