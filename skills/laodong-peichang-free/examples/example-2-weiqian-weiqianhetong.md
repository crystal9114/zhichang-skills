# 样例 2：一年多没签合同、被欠薪后自己走（杭州）

## 用户输入

> 杭州，2025年5月12日入职，一直没签合同，月薪7500。公司连续两个月没发工资，我10月20日发了书面通知说因为欠薪解除合同。今天2026年11月3日，能要什么钱？

## 判断过程

1. 离职方式：单位欠薪、员工书面以欠薪为由解除 → `--reason 被迫离职`（第三十八条），有 N。
2. 合同：一直没签 → `--contract 没签`，算二倍工资差额。
3. 欠的两个月工资是另一项（应发减实发），本技能不进脚本，回答里单列。

## 跑的命令

```bash
python3 scripts/peichang.py quick --entry 2025-05-12 --leave 2026-10-20 --wage 7500 --reason 被迫离职 --city 杭州 --contract 没签 --apply 2026-11-03
```
