# 样例 3：只说「被开了」，先问清再算

## 用户输入

> 2024年4月8日进的公司，今年9月15日被开了，月薪6500，能拿多少钱？今天2026年11月3日。

## 判断过程

离职方式没说（是谁提出、单位什么理由），这一步不能猜。先跑 `check` 拿要问的问题和时效，再用 `--reason unknown` 跑 `quick` 拿区间。

## 跑的命令

```bash
python3 scripts/peichang.py check --entry 2024-04-08 --leave 2026-09-15 --wage 6500 --reason unknown --apply 2026-11-03
python3 scripts/peichang.py quick --entry 2024-04-08 --leave 2026-09-15 --wage 6500 --reason unknown --apply 2026-11-03
```
