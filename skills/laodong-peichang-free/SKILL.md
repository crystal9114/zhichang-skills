# 劳动赔偿计算器·N/N+1/2N与仲裁时效

**铁律：问到能拿多少钱、公司给的对不对、还能不能告，一律先在技能目录里跑 `python3 scripts/peichang.py quick …`（时效和缺什么先跑 `check`），把命令和输出贴进回答，再下结论。不心算、不凭印象报数。** 脚本输出里已经写好法条全称和条款号、算式、时效截止日、存疑项和「以当地劳动人事争议仲裁委员会的口径为准」，照搬进回答，不删不改数字。

**输出最上面有【回答开头照抄】的，把那几句原样当回答第一段（不改写、不换成金额结论、不删句子）；有【还要问（逐条照抄）】的，每条原样单独写进回答的「还要问」，不合并成一问、不挪进行动清单。** 派遣、外包、境外、刑事、调岗降薪、孕期等受保护员工被按第四十条或第四十一条解除、严重违纪或试用期不合格被开、「X 年多」这几种情形，脚本都会打出这两段。回答第一段直接从照抄的句子开始，前面不加「先说结论」之类的话，也不加自己的总结句。

## 什么时候用

中国大陆的劳动关系，员工被解除或终止劳动合同、离职时要算的钱。用户常这么说：

- 「公司突然辞退我，赔 N+1 还是 2N」「被裁员了能拿几个月」「公司说按 3.5 个月给，对吗」
- 「工资基数含不含奖金、年终奖」「月薪很高，补偿有没有封顶」「按税前还是税后」
- 「入职一年多没签合同，双倍工资能要几个月」「年假没休离职了能折多少钱」
- 「去年被辞退的，超过一年还能告吗」「劳动仲裁时效怎么算」
- HR：「辞退一个入职 3 年月薪 8000 的员工，各种走法要花多少」

不用：工伤待遇、劳务派遣和外包、境外用工、外籍人员、退休返聘、编制人员、竞业限制和股权、刑事、要律师代理出庭（见[超出范围怎么答](#超出范围怎么答)）；加班费、违法试用期只给手算口径，不进脚本（references/calc-rules.md 第 7 节）。

## 四步做法

| 步 | 输入 | 做什么 | 结果 |
|---|---|---|---|
| 1 判范围 | 用户原话 | 有没有工伤、派遣、外包、境外、刑事、要代理 | 超范围走 G，不出确定金额 |
| 2 问离职方式 | 原话里的解除经过 | 对照下表定 `--reason`；定不了先问 | 一个代码，或 `unknown` |
| 3 跑脚本 | 日期、工资、城市、合同、年假 | `check` 看缺什么和时效；`quick` 算钱 | 脚本输出原文 |
| 4 写回答 | 脚本输出 | 结论 → 金额表 → 时效 → 存疑 → 还要问 → 附命令和输出 | 交给用户的回答 |

## 第一步：先判范围

原话里出现下面任何一样，先跑 `python3 scripts/peichang.py check --flags <情形>` 拿到该怎么说，然后按[超出范围怎么答](#超出范围怎么答)回（用户问能赔多少的，再加 `--rough` 跑粗算参考数）：工伤（work_injury）、派遣（dispatch）、外包或驻场（outsourcing）、在境外工作或外派出国（overseas）、外籍港澳台（foreign）、已退休返聘（retired）、编制（civil_servant）、十人以上集体（group）、竞业股权（non_compete）、非全日制（part_time）、刑事或报警（criminal）。被调岗降薪、穿小鞋、还没走的，加 `--flags 调岗`（照算，不停）。

孕期产期哺乳期、医疗期内、满 15 年且离退休不足 5 年不是超范围，照算并加 `--flags 孕期`（或 医疗期、老员工）：单位按第四十条、第四十一条解除或到期终止的，脚本自动转按 2N。

## 第二步：先问清离职方式

离职方式决定是 0、N、N+1 还是 2N，差别最大，**这一步不能替用户猜，也不能替用户断定是违法解除**。

| 用户原话 | --reason | 还要问什么 |
|---|---|---|
| 「微信说明天别来」「口头让走人、没给理由」 | illegal_dismissal（违法解除） | 有没有书面解除通知、写的什么理由；回答写「如果单位拿不出合法理由和证据，可以主张 2N」 |
| 「公司提出协商、给 N+1 让签字」 | employer_negotiated（协商-单位提出） | 协议签了没有；+1 是谈判价不是法定 |
| 「说我不能胜任」「医疗期满」「部门撤了、岗位没了」 | objective（第四十条） | 有没有提前 30 天书面通知（`--notice 有/没有/未知`）；不能胜任的有没有先培训或调岗 |
| 「公司裁员」 | layoff（裁员） | 一般不用再问 |
| 「合同到期公司不续」 | contract_expired（到期不续） | 公司有没有提出按原条件或更好条件续签、你拒了（拒了加 `--renew-declined`） |
| 「欠薪」「不交社保」我提的离职 | employee_forced（被迫离职） | 辞职信上写的理由是不是欠薪、未缴社保 |
| 「我自己辞职」「被逼写了辞职信」 | employee_resign（主动辞职） | 辞职信写的理由；写「个人原因」的按 0 算并提示风险 |
| 「被穿小鞋」「调岗降薪受不了想走」，还没走 | `--reason unknown --flags 调岗`；按 employee_resign 和 employee_forced 各说结果 | 讲清：自己辞职一般 0；只有单位欠薪、未足额缴社保、未按约定提供劳动条件等《中华人民共和国劳动合同法》第三十八条情形，并以此书面解除才有 N。问调岗有没有降薪、有没有书面通知、有没有欠薪或少缴社保；提醒先留证据，别写「个人原因」辞职 |
| 「说我严重违纪」「试用期不合格」 | misconduct / probation_fail | 违反哪条制度、制度签收过没有、单位有什么证据 |
| 「被公司开了」「让我走了」，没细说 | unknown（未确认） | 是谁提出的、单位给的理由、签过什么（先跑 check） |

其他关键事实：入职日、离职日、离职前 12 个月税前应发（含绩效提成奖金补贴，年终奖要分开说）、城市、合同签没签。

**材料不全也要交能用的东西，不能只回一串问题。** 回答同时给四样：① 要补的问题（最多 3 个，按 check 给的顺序，每个写为什么会改变结果）；② 每种离职方式怎么算的对照（0 / N / N+1 / 2N 各是什么前提）；③ 一个按假设跑出来的数（用户只说「干了 4 年」就用 `--years 4`，没说离职日就不给 `--leave`，脚本会把假设写出来；离职方式不清用 `--reason unknown`），明写「按假设估，不是结论」；④ 现在就能做的事（留哪些证据、要解除证明、时效截止日）。「3 年多」这种说法零头决定是 3.5 还是 4 个月（零头不满 6 个月 3.5，满 6 个月 4）：跑 `--years 3多`，脚本在【回答开头照抄】里把两种月数和金额都写好，【还要问】里有准确入职日、离职日，照抄，不替用户挑一种。脚本输出开头有「按假设估，不是结论」时，回答里的金额都要这样标，不能写成「按你的事实」。不影响结果的写明假设照算（例如月薪不高没说城市，写「未做封顶判断，一般碰不到」）。不编具体日期和工资当事实。

## 第三步：跑脚本

工作目录就是技能目录。用户说了「今天是……」就加 `--apply 那天`，没说按今天。

```bash
# 时效、缺什么、要不要停（事实不全或离职方式没说清时先跑）
python3 scripts/peichang.py check --leave 2025-08-31 --reason unknown --apply 2026-11-03
# 算钱
python3 scripts/peichang.py quick --entry 2021-03-15 --leave 2026-09-30 --wage 15000 --reason 违法解除 --city 上海 --contract 签了 --apply 2026-11-03
```

常用参数（全表见 references/cli.md）：

- 工资三选一：`--wage 15000`（月平均税前应发）；`--wages12 9000,9000,12000`（逐月）；`--parts 基本工资=6000,绩效=2000,年终奖=24000`（名字带「年」的自动 ÷12）。
- `--city 北京` 查社平工资做三倍封顶（表里有北京、上海、天津、广州、杭州、宁波、成都、长沙、西安、武汉、郑州）；没有的城市用 `--avg-wage` 给当地人社局公布数。
- `--contract 签了/没签/补签`（补签加 `--signed-date`）；`--notice 有/没有/未知`；`--al-years 累计工作年数 --al-taken 今年已休天数` 算未休年假。
- 离职方式没问清用 `--reason unknown`：只出四种情形对比，不出结论。
- 只知道干了几年用 `--years 4`，「3 年多」写 `--years 3多`（代替 `--entry`，反推入职日并标为假设）；不给 `--leave` 时按 `--apply` 那天算并标为假设。
- 派遣、外包、境外这类要停的情形，用户要个参考数时加 `--flags 派遣 --rough`：脚本按普通劳动关系粗算，输出开头写明「粗算，不是结论」和前提。

**用户问「公司给的对不对」**：按用户给的日期和工资跑，脚本算出多少就是多少，不改入职日、离职日去凑公司的数；和公司的数不一样就直接说公司算错在哪、差多少。

**用户给的数本身有错**（2 月 30 日、负数工资、离职早于入职）：脚本会报 E03 / E04。回答指出哪里错、请用户核对，可以讲清怎么算（公式），但**不自己改成别的日期或金额再报结果**。

脚本报错时打印「错误码、原因、怎么办」三行（码表 references/errors.md），照「怎么办」问用户或改命令，不要绕过脚本心算。

## 第四步：写回答

顺序固定（按场景的示范骨架见 references/answer-patterns.md）。脚本输出有【回答开头照抄】的，它就是回答开头（里面已经有一句话结论、月工资基数那句、时效那句），原样放，第 1 项和第 3 项不用再另写；有【还要问（逐条照抄）】的，第 5 项先逐条照抄它，再补别的。

正文引用法条一律写全称和条款号（《中华人民共和国劳动合同法》第四十七条、《中华人民共和国劳动争议调解仲裁法》第二十七条），不缩写成《劳动合同法》。

脚本「结论」下面的补充句（如「主动辞职没有经济补偿 N」「裁员法定没有代通知金」「违法解除是否成立由仲裁委认定」）和「存疑」行要写进回答正文，不能只留在末尾附的脚本输出里：用户不一定翻到附录。

1. **一句话结论**：合计多少、凭什么定性。违法解除写成条件句：「如果单位拿不出合法解除的理由和证据，可以主张 2N 共 X 元」。离职方式是 unknown 的，第一句写「先确认……」，不报结论金额。
2. **金额表**：项目、金额、算式、依据（照抄脚本的法条全称和条款号）。2N 不和 N、代通知金相加。月工资基数照这句写进正文：「按离职前 12 个月平均税前应发算（扣社保、个税之前，不是到手工资），含绩效、提成、奖金、补贴，年终奖 ÷12」。
3. **时效**：截止日、还剩几天；已过的写「本来能要 X 元，但已过一年仲裁时效」，紧接着问有没有中断的记录，不直接说「告不了」。
4. **存疑和地方口径**：脚本「存疑」开头的每一条都带上，保留「以当地劳动人事争议仲裁委员会的口径为准」。
5. **还要问 / 下一步**：脚本「还要问」里会改变结果的，写成直接问用户的问题；下一步写留什么证据、去哪个仲裁委（劳动合同履行地或单位所在地，不收费）。
6. **附：脚本核算**：贴出跑的命令和输出原文，整段原样贴：不节选、不删段、不写「略」「同上」、不改写，空行可以去掉。贴的必须是会话里真跑过的命令，一字不改；报过错又换参数重跑的，贴最后一次真跑的命令和输出，并照实写一句「第一次用 …… 报了 E0x，改成 …… 重跑」。没跑成的命令不要写进来，也不要说「请忽略之前的结果」。

用户主动问仲裁申请书或 Excel 测算表时，如实说本技能只做速算和体检，同作者另有能出这两样文件的收费版；不主动推荐。

## 超出范围怎么答

不要拿拒绝开头，也不要一句「找律师」打发。派遣、外包、境外先跑 `check --flags <情形>`（给了工资和年限再跑 `quick … --flags <情形> --rough`），回答第一段就是脚本的【回答开头照抄】：不出确定金额、只给 N 到 2N 粗算区间、律师或仲裁委是首要下一步；不按普通辞退出 N/2N 结论表。其余照下面的顺序：
1. 这类情况和普通辞退哪里不同、一般规则怎么定（向谁主张、按什么算、法条全称和条款号）。
2. 用户问「能赔多少」的：用用户给的工资和年限加 `--flags <情形> --rough` 跑粗算，给区间（比如 N 到 2N），写明前提和「以律师或仲裁委核定为准」；用户没给工资年限的只给公式，不自己编数。
3. 写明「X 部分不在本技能范围」（刑事写「刑事部分不在本技能范围，构不构成、判多少由公安、检察院、法院认定」，刑事先跑 `check --flags 刑事`，照抄它的开头；境外写「本技能只按中国大陆劳动法测算」）。
4. 先走什么程序、找谁：律师、当地劳动人事争议仲裁委员会窗口、12348 法律援助热线、劳动监察（12333）。
5. 现在就能做的准备：证据清单、时效截止日。

- **要律师代理、出庭、写律师函**：明说本技能不能当代理人、不能出庭，指向律师、12348 法律援助热线、当地劳动人事争议仲裁委员会窗口。然后给：可以委托谁（律师、基层法律服务工作者、工会推荐的人、近亲属、法律援助机构，委托要写授权委托书）；开庭前要备的（陈述提纲：入职、解除经过、请求金额；证据目录：合同、工资流水、解除通知、聊天记录；对方可能的说法和你的回应）；如果事实给了，顺手跑 quick 把请求金额算好。
- **刑事**（告老板拒不支付劳动报酬罪、被单位报警说职务侵占）：刑事部分要找刑辩律师或向公安、劳动监察反映，**不替用户断定构不构成犯罪、会判几年**。但要讲清法律框架（照 references/laws.md 原文）：拒不支付劳动报酬罪规定在《中华人民共和国刑法》第二百七十六条之一，一般要先经劳动监察等部门责令支付、逾期仍不支付才追究，法定刑档以条文为准、个案由法院认定。欠的工资可以同时申请劳动仲裁或向劳动监察投诉追讨；被报警又被开除的，劳动赔偿部分取决于解除理由能不能成立（单位举证），事实齐了照常算。
- **派遣、外包**：劳动合同在谁那里就向谁主张。派遣：劳动合同在派遣单位，被退回后无工作期间派遣单位要按当地最低工资按月付报酬，用工单位造成损害的两家承担连带责任，仲裁时两家都列为被申请人（《中华人民共和国劳动合同法》第九十二条）；派遣单位解除的，按普通规则算 N 或 2N。外包驻场：先分清和谁签的劳动合同、谁发工资、谁交社保，一般向签合同的外包公司主张，不是向甲方；名为外包实为派遣的另判。
- **境外用工**：先分清是国内公司外派（劳动合同在国内公司，一般可按中国法主张）还是境外公司直接雇佣（多按当地法），本技能只按中国大陆劳动法算；境外部分找熟悉涉外劳动的律师。
- **工伤**：先做工伤认定和劳动能力鉴定，待遇按《工伤保险条例》和当地规定。

HR 问「怎么辞退成本最低」：照算对比表、讲清每种走法的前提，不教逼员工自离、不发工资逼走、倒签协议这类做法。

## 口径速查

脚本已按这些算好，回答里解释给用户听时用。逐项细则 references/calc-rules.md，法条原文 references/laws.md。

| 项目 | 怎么算 | 依据 |
|---|---|---|
| 经济补偿 N | 每满一年 1 个月；零头满 6 个月按 1 年，不满 6 个月按半个月（3 年 6 个月 = 4 个月，不是 3.5） | 《中华人民共和国劳动合同法》第四十六条、第四十七条 |
| 月工资基数 | 离职前 12 个月平均**税前应发**，含绩效提成奖金津贴补贴，年终奖 ÷12；低于最低工资按最低工资 | 第四十七条第三款；《中华人民共和国劳动合同法实施条例》第二十七条 |
| 高收入封顶 | 月工资 > 当地上年度社平 × 3：基数按 3 倍、年限最多 12 年；**没超过就没有 12 年上限** | 第四十七条第二款 |
| 代通知金 | 只在第四十条解除且没提前 30 天书面通知时有，按上一个月工资，不封顶 | 第四十条；实施条例第二十条 |
| 2N | N 的标准 × 2，年限从用工之日起算，不再另拿 N 和代通知金 | 第四十八条、第八十七条；实施条例第二十五条 |
| 二倍工资差额 | 用工满一个月次日起到补签前一日，最多 11 个月；满一年视为无固定期限合同 | 第十条、第八十二条、第十四条第三款 |
| 未休年假 | 日工资（剔除加班费月工资 ÷21.75）× 天数 × 200%（300% 里含已发的 100%） | 《企业职工带薪年休假实施办法》第十条至第十二条 |
| 仲裁时效 | 一年，从离职日起算；书面催要、投诉、单位答应付钱会中断，重新算一年 | 《中华人民共和国劳动争议调解仲裁法》第二十七条 |

## 常见问题

| 问题 | 怎么办 |

| 脚本报 E03 / E04 | 日期写成 2024-03-15；工资只写阿拉伯数字的税前月应发，不带「元」「k」，0 元和负数会被拦 |
| 脚本报 E05 | 缺工资或补签日期：问用户要，别编 |
| 脚本报 E06 | 离职方式或情形词不在表里：查 references/codes.md，没问清写 unknown |

## 文件清单

- `SKILL.md`：本文件，核心做法。
- `scripts/peichang.py`：入口，`check` 体检、`quick` 算钱；只用 Python 3.9+ 标准库，不联网、不写文件。
- `scripts/ldlib/`：calc.py 逐项测算、case.py 离职方式与输入校验、dates.py 年限与日期、avgwage.py 读社平表、laws.py 取法条全称、lead.py 打【回答开头照抄】和【还要问（逐条照抄）】、render.py 排版、errors.py 错误码、model.py 数据结构。
- `references/cli.md` 参数全表 · `references/codes.md` 离职方式与特殊情形代码 · `references/calc-rules.md` 逐项口径 · `references/laws.md` 法条原文 · `references/avg-wage.md` 主要城市社平工资（带年份、口径、出处） · `references/answer-patterns.md` 按场景的回答骨架 · `references/errors.md` 错误码。
- `examples/`：三套完整样例（输入、命令、脚本输出、回答）。
- `tests/test_peichang.py`：单测（`python3 -m pytest tests -q`），含 0 元、负数、超范围数、空值、乱码参数等反向用例。

依赖：Python 3.9 以上。不需要联网、不需要账号、不收集个人信息。本技能按用户提供的事实测算，不是法律意见。
