# 样例

两套完整样例，输入都是演示用的条目（不是哪位买家的论文），命令和输出是脚本真跑的原样结果。

| 文件 | 场景 | 命令 |
|---|---|---|
| 01-列表速改-2025.md | 贴列表改成 2025 版：著者超过 3 人加「等 / et al.」、全角改半角、学位论文补所在地、缺页码和引用日期标【待补】 | `fix -` |
| 02-2015转2025.md | 2015 版列表转 2025 版，6 处规则差异全部命中的一份 | `upgrade -` |

自己试：`python3 scripts/gb7714.py fix examples/sample-list.txt`（sample-list.txt 就是样例 1 的输入）。
