# 参考文献 GB/T 7714 速改（2015 / 2025）

**铁律：凡是要输出改好的条目，一律先跑 `scripts/gb7714.py`，把命令和脚本输出贴进回答，再下结论。** 条目怎么排、缺什么、改了哪几处，以脚本输出为准，不凭记忆改格式，也不写「建议你自己跑脚本核对」。脚本只用 Python 标准库、不联网，同一输入永远同一输出。

## 目录

1. 先跑脚本：材料 → 命令
2. 动手前要定的两件事

## 1. 先跑脚本：材料 → 命令

买家贴的条目原样放进 heredoc，一行一条，带不带 [1] 都行（不要先替他改再喂给脚本）：

```bash
python3 scripts/gb7714.py fix - <<'EOF'
<买家贴的条目，原样>
EOF
```

| 买家给了什么、要什么 | 跑哪条 |
|---|---|
| 贴了列表要改格式，说了 2025 / 新国标 / 最新的，或没说版本 | `fix -`（默认 2025） |
| 说了 2015，或「学校模板写的是 2015」 | `fix - --edition 2015` |
| 「2015 版转 2025」「旧格式换成新国标」「期刊改用 2025 了」 | `upgrade -` |
| 学校要求作者全列 / 列前 N 位 | 加 `--max-authors 50` / `--max-authors N` |
| 学校要求「等」前不加逗号 | 加 `--no-etal-comma` |
| 买家告诉了访问网页的日期（如「都是今天查的」） | 加 `--cite-date YYYY-MM-DD` |
| 学校或期刊要求必须写 DOI | 加 `--require-doi` |
| 买家给的是文件路径（.txt / .md） | 把 `-` 换成路径；.docx、PDF 脚本不读（E02），请他复制列表贴进来 |

- 要写其他参数先跑 `python3 scripts/gb7714.py -h` 看，不编参数。参数全表见 references/script-usage.md。
- 脚本报 E 码：照它给的「怎么办」处理，错误码表在 @references/faq.md。

## 2. 动手前要定的两件事

能从材料里推断的就推断并写明，推断不了又会改变结果的才问，一次问完：

1. **版本**：说了照说的。「新国标」「最新」「今年的」= GB/T 7714—2025（2025-12-02 发布，2026-07-01 实施）。没说版本 → 按 2025 跑，回答第一句写明「没说版本，按 GB/T 7714—2025；学校模板仍写 2015 的告诉我，改按 2015 重跑」。说「按学校模板」「格式审查」却没给模板 → 先按 2025 做一版，同时请他发学校规范里参考文献那一页，学校另有规定以学校为准。
2. **文献类型、著者、年份**：原文有类型标识就用；没有的，脚本按结构判并标「要你核对」。脚本判不出类型（输出「这条拆不开」）、缺著者、缺出版年时，不替他猜：在回答里点名是第几条、缺什么，问他原文出处，或写明假设（「按期刊论文处理，若是会议论文请告诉我」）。

## 3. 按场景答：回答里必须有什么

| 场景 | 回答里必须有 |
|---|---|
| 贴列表、要改格式 | ①一句结论：依据 GB/T 7714—20xx、共几条、改了几条、几条要补；②代码块放改好的完整列表（脚本「改好的列表」原样）；③逐条改了什么（照脚本「逐条改了什么」，用中文写清原来怎样、现在怎样）；④要补 / 要核对的表 |
| 2015 转 2025 | 以上四块，外加：6 处规则差异命中了哪几处（写编号和名称、各命中哪几条）、哪几处没命中；照脚本「6 处规则差异命中情况」表 |
| 有缺项（页码、卷期、出版地、DOI、引用日期、著者） | 改好的列表里该条末尾留【待补：xx】；正文写清缺什么、去哪查（期刊官网、知网文章页、图书版权页）。买家要你「随便填一个」也不填，说明会被查出来 |
| 只写 1~2 位作者就加了「等 / et al.」 | 不编后面的人名，哪怕你认得这篇文献、记得作者是谁，也一个名字都不写；说清两种改法：原文作者多于 3 人 → 补满前 3 位再加省略；原文就这几位 → 删掉「等」 |
| 英文文献 | 超过 3 人用「et al.」不用「等」；姓在前、名缩写不加点；2025 版姓首字母大写（Smith J A），2015 版姓全大写（SMITH J A） |
| 只说「帮我改参考文献」没贴条目 | 不跑脚本，请他把列表贴进来（一行一条），并问用 2015 还是 2025 |
| 贴的是正文段落、不是参考文献 | 说明这是正文，不是参考文献条目，不编成一条文献；告诉他正文里怎么标引注（顺序编码制在引用处加 [1]，学位论文多用上标；同一处引多篇写 [1,3]、[1-3]），请他把文后参考文献列表贴来 |
| 学校规定和国标不同（作者列几位、「等」前逗号） | 用参数跑；正文写明「此处按学校规定，和国标不同（国标超过 3 人列前 3 人，「等」前有逗号）」，脚本输出里有这句，照写 |
| 要 APA、MLA、IEEE，或期刊自定的非国标格式（年份放作者后、加引号、斜体、vol.、pp.） | 说明本技能只出 GB/T 7714，不写这些格式的条目，也不写「照这个排就是」的字段对照行或示范行；同时给能直接用的路子：① 投稿须知或期刊官网的参考文献示例；② Zotero、EndNote 里把样式换成该期刊或 APA / IEEE 样式一键重排（Zotero 中文样式库收了大量中文期刊样式）；③ 跑脚本给出这条的 GB/T 7714 写法，字段已拆对、缺项已标，换格式时照着填不会漏 |
| 要核实文献真不真 | 说明脚本不联网，不能替他断言真假；跑脚本把条目格式改好、标出格式上的疑点；再给 3 步自查：① 知网 / 谷歌学术按完整题名加引号搜；② 有 DOI 的在 doi.org 打开，看跳到的是不是同题名同作者；③ 去期刊官网该卷期目录核页码。三步都对上了再用；对不上的先别放进论文，找到原文再说。不替他下「是真的」「是编的」「基本可以判定」这类结论 |
| 只记得题名、要你补全作者卷期页码 | 说明不能代查、不编作者卷期页码；把他给的题名、刊名、年份照写成条目跑脚本，缺的项由脚本标【待补】，告诉他在知网「高级检索」按「篇名 + 刊名 + 年份」找到原文后照文章页补 |
| 要写综述、改正文、降重 | 说明不在范围：不写综述正文、不列推荐文献；能做的是把他的参考文献列表改成 GB/T 7714，请他贴来 |
| 要 Word 里批量改、正文引注对号、重新编号、著者-出版年制互转 | 说明这个精简版只改文后参考文献列表、不读 Word；用户问有没有能做的，如实说同一作者的收费版「参考文献国标校对与转换」能做 Word 批注和正文对号；现在能做的是把列表贴来改格式 |

## 4. 交付格式

按下面顺序给，没内容的块整块不写：

1. **结论**：一两句话。写依据（GB/T 7714—2025 写上「2026-07-01 实施」）、共几条、改了几条、几条要补；做了假设的写在这里。学校或期刊另有模板的，以学校/期刊为准。
2. **改好的列表**：代码块，脚本输出原样，拿来就能贴进论文。
3. **要你补 / 要你核对**：表格「条目 | 项目 | 说明」，照脚本。
4. **逐条改了什么**：每条一行「[n] 改了什么」，只列改过的，没改的合并成一句「第 x、y 条原本合格」。
5. **2015 → 2025 差异**（upgrade 才有）：命中几处、哪几处、各在哪几条；未命中哪几处。
6. **跑了什么**：末尾附真跑的命令和脚本输出（可折叠成代码块）。

结论、改动说明、要补的内容都写在正文里，不只放在末尾代码块。不写「仅供参考」「建议自行核对格式」这类空话，脚本已经算定的就直接说。

## 5. 什么时候停下来

- 没给任何条目：请他贴，停。
- 一条拆不开（缺分隔符、乱码、只有题名）：脚本会原样保留并标「要你核对」，照实转告，请他给原文出处；不重组成一条看似完整的文献，不猜类型。
- 学校规定和国标冲突又没说以谁为准：问一句再改。
- 范围外的（别的格式、查真伪、找文献、写综述、Word 文件）：说明不做，能做的部分照做。
- 超过 500 条：脚本报 E06，请他分批贴。
