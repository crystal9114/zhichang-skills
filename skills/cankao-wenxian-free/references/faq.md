# 常见问题与错误码

## 错误码（脚本出错时打印「E 码 + 原因 + 怎么办」，不打印程序堆栈）

| 码 | 现象 | 怎么办 |
|---|---|---|
| E01 | 找不到文件，或给的是文件夹 | 检查路径，路径有空格加引号；也可以用 `-` 直接贴列表 |
| E02 | 给的是 .docx、.doc、.pdf、.wps、表格 | 精简版只读文字：把参考文献列表复制出来贴进对话或存成 .txt |
| E03 | 输入是空的 | 把参考文献列表贴进来，一行一条 |
| E04 | 没认出参考文献条目，或每条都拆不开 | 确认贴的是参考文献（著者. 题名[类型]. 出处），不是正文段落 |
| E05 | 参数不对：模式不是 fix/upgrade、`--max-authors` 不在 1~50、`--cite-date` 不是有效日期或晚于今天 | 照提示改，如 `--cite-date 2026-11-03` |
| E06 | 一次超过 500 条，或文件超过 2 MB | 分批，每批 500 条以内 |
| E07 | 文字编码认不出 | 记事本打开 →「另存为」→ 编码选 UTF-8 |
| E98 | 中途按了取消 | 重新运行 |
| E99 | 脚本内部出错 | 把出错的那几条单独跑一遍找出是哪条，那条按 references/rules.md 手工改 |

## 使用中的问题

**没说用哪一版？** 默认按现行的 GB/T 7714—2025（2026-07-01 实施）。学校模板仍写 2015 的，加 `--edition 2015` 重跑。学校或期刊另有模板的，以学校/期刊为准。

**为什么不帮我把缺的页码、DOI 填上？** 页码、卷期、DOI、出版地、引用日期只有原文里有，凭印象写错一个数比空着更糟（送审、编辑会按 DOI 去查）。脚本在该条末尾标【待补：页码】，照知网文章页、期刊官网、图书版权页抄上即可。唯一会自动补的是常见出版社、大学的所在地，补了也标「请核对」。

**引用日期填哪天？** 你实际打开那个网页的日期，只有你知道。都是同一天查的，用 `--cite-date YYYY-MM-DD` 一次补齐。2025 版只有网页 [EB/OL]、数据集 [DS/OL]、预印本 [PP/OL] 写引用日期；2015 版所有 /OL 都写。

**中英混排，「等」和「et al.」怎么定？** 看这条文献本身的语种：中文文献用「等」，英文文献用「et al.」，和作者国籍无关。

**学校要求作者全列 / 「等」前不加逗号？** 加 `--max-authors 50` / `--no-etal-comma`。学校规定和国标不一样时以学校为准。

**能转 APA、MLA 吗？** 不能，只输出 GB/T 7714；APA、MLA 写法的英文文献可以转成国标。

**会检查文献是不是真的吗？** 不会，脚本不联网。只指出格式上的疑点（出版年在未来、DOI 不像、页码倒置、两条题名相同）。

**同一份列表跑两次结果会不会不一样？** 不会。排版由脚本按规则算，同一输入永远同一输出。

**没装 Python？** 脚本只要 Python 3.8 以上，不用装任何库。实在没有，按 references/rules.md 第 8 节的顺序手工逐条改，规则一样。
