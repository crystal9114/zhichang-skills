# GB/T 7714 著录规则速查（2015 / 2025）

脚本 `scripts/gb7714.py` 按这份规则写。没有终端、只能手工改时，逐条照这份做，结果和脚本一致。
国家标准原文属公共材料，示例照录自 GB/T 7714—2015、GB/T 7714—2025 附录。

## 目录

0. 2015 → 2025 的 6 处规则差异（upgrade 模式判的就是这 6 处）
1. 先定版本（两版对照全表）
2. 文献类型标识和载体标识
3. 著者（责任者）
4. 著录符号和标点
5. 各类型的著录格式（附示例）
6. 必备项：缺了要买家补的
7. 日期、页码、DOI
8. 手工校对顺序（没有脚本时）

## 0. 2015 → 2025 的 6 处规则差异

| # | 差异 | GB/T 7714—2015 | GB/T 7714—2025 | 怎么认出来 |
|---|---|---|---|---|
| 1 | 西文、拼音姓的大小写 | 姓全大写 `SMITH J A` | 姓首字母大写 `Smith J A` | 有西文或拼音个人著者 |
| 2 | 在线文献的引用日期 | 所有 /OL 都写 `[引用日期]` | 只有 [EB/OL] [DS/OL] [PP/OL] 写，[J/OL] [M/OL] [D/OL] 等删去 | [J/OL] 等带 `[YYYY-MM-DD]` |
| 3 | 标准的标准号位置 | `题名: 标准号[S]. 出版地: 出版者, 年.` | `标准号 标准名称[S].` | 类型是 [S] |
| 4 | 报告、专利的著录格式 | 报告按图书写出版项；专利 `题名: 专利号[P]. 公告日期.` | 报告 `题名: 报告编号[R]. 发布日期: 页码.`；专利号带国别前缀 CN，可加引文页码 | 类型是 [R] 或 [P] |
| 5 | 学位论文的引文页码 | 可选 | 有则必备 | 类型是 [D] |
| 6 | 新增预印本 [PP] | 没有 [PP]，按 [EB/OL] 或 [Z] | `[PP/OL]` | 网址是 arXiv、bioRxiv、medRxiv、ChinaXiv、SSRN 等预印本平台 |

不改著录结果、只改说法的变化：「专著」改称「图书」；[EB] 改指网站、网页；DOI 改称永久标识符，网址里已含 DOI 可不重复写；会议论文也可写成 `[C]//会议名称, 会议年份: 页码.`。

## 1. 先定版本

| | GB/T 7714—2015 | GB/T 7714—2025 |
|---|---|---|
| 状态 | 被 2025 版代替 | 2025-12-02 发布，2026-07-01 实施 |
| 谁还在用 | 多数高校学位论文模板仍写 2015 | 期刊陆续改用；新改模板的学校 |
| 西文、拼音姓 | 全大写：`SMITH J A`、`LI J N` | 首字母大写：`Smith J A`；拼音名宜用全称 `Li Jiangning` |
| 在线文献引用日期 | 所有 /OL 文献都要 `[引用日期]` | 只有网站网页 [EB/OL]、数据集 [DS/OL]、预印本 [PP/OL] 要；[J/OL] [M/OL] [D/OL] 不写 |
| 标准 [S] | `题名: 标准号[S]. 出版地: 出版者, 年: 页码.` | `标准号 标准名称[S].`（编号在前，无出版项） |
| 报告 [R] | 按图书：`出版地: 出版者, 年: 页码` | `题名: 报告编号[R]. 发布日期: 页码.`（也可带出版项） |
| 专利 [P] | `题名: 专利号[P]. 公告日期.` | `题名: 专利申请号[P]. 公告（公开）日期: 引文页码.` 号码常带国别前缀 CN |
| 会议论文 [C] | `[C]//编者. 论文集名. 出版地: 出版者, 年: 页码.` | 也可 `[C]//会议名称, 会议年份: 页码.`（未正式出版的会议录） |
| 学位论文 [D] | 引文页码可选 | 引文页码「有则必备」 |
| 新增 | — | 预印本 [PP]、载体缩微资料 /MM；EB 改指「网站、网页」；「专著」改称「图书」；DOI 改称「永久标识符」，网址里已含 DOI 可不重复写 |
| 无卷号期刊 | `文献, 2013(1): 56-75.` | `文献，2013（1）：56–75.`（同样年和期之间不加逗号） |
| 标准原文排版 | 半角 `.` `:` `,` 后加空格 | 句点半角；中文逗号、冒号、括号排成全角（脚本 `--punct mixed`）。学校没规定时半角也可 |

**判断**：买家说了版本照说的；没说版本按现行的 2025 做并写明，学校模板仍写 2015 的改按 2015；学校或期刊自己的规定永远优先于国标。

## 2. 文献类型标识和载体标识

| 类型 | 代码 | 类型 | 代码 |
|---|---|---|---|
| 图书（普通图书、专著） | M | 标准 | S |
| 会议录、会议论文 | C | 专利 | P |
| 汇编 | G | 数据库 | DB |
| 报纸 | N | 计算机程序 | CP |
| 期刊 | J | 电子公告（2015）/ 网站网页（2025） | EB |
| 学位论文 | D | 档案 | A |
| 报告 | R | 舆图（2015）/ 地图（2025） | CM |
| 数据集 | DS | 预印本（仅 2025） | PP |
| 其他 | Z | | |

载体：磁带 MT、磁盘 DK、光盘 CD、联机网络 OL、缩微资料 MM（仅 2025）。电子资源类型和载体都写：`[J/OL]`、`[M/OL]`、`[EB/OL]`、`[DS/OL]`、`[PP/OL]`。

易错：
- `[学位论文]`、`[硕士论文]`、`[Thesis]` → `[D]`；`[j]` → `[J]`；`[J/0L]`（数字 0）→ `[J/OL]`；`[EB]` 网页 → `[EB/OL]`。
- 论文集里的一篇用 `[C]`，书里的一章用 `[M]`，后面都用 `//` 接出处。
- 印刷本带网址：引自网络版改 `[J/OL]`（2015 还要补引用日期），引自印刷版删网址。拿不准就问买家。
- 2015 版没有 [PP]：预印本按 [EB/OL] 或 [Z]，2025 版用 [PP/OL]。

## 3. 著者（责任者）

1. **人数**：不超过 3 个全部照录；超过 3 个只录前 3 个，后加「, 等」（中文文献）或「, et al.」（西文文献）。按文献本身的语种定用「等」还是「et al.」，不按著者国籍。
   - `袁训来, 陈哲, 肖书海, 等.` `Fordham E W, Ali A, Turner D A, et al.`
   - 原文只列 1~2 人就写了「等」：不能自己编出第 2、3 位，列进待补，请买家照原文补。
   - 正好 3 人加了「等」：说明原文作者多于 3 人，保留。
2. **姓在前名在后**，名可缩写为首字母，缩写名后**不加点**：`Smith J. A.` → 2015 `SMITH J A`、2025 `Smith J A`。
3. 「名在前」的西文名（`John Smith`、`J. A. Smith`）倒成姓在前；全拼两词拿不准哪个是姓时问买家。
4. 前缀和后缀跟姓走：`De Morgan A`、`Peebles P Z Jr`、`Veen P H v d`。
5. 中文著者之间用「, 」，去掉姓名中间的空格；不用「、」「和」「and」「&」连接。
6. 机关团体照录全称：`中国科学院物理研究所`；西文团体上下级用「.」分：`Stanford University. Department of Civil Engineering`。
7. 无著者：顺序编码制直接从题名开始；著者-出版年制写「佚名」或「Anon」。
8. 译者等其他责任者放在类型标识后：`[M]. 胡泳, 范海燕, 译. 海口: 海南出版社, 1996.`

## 4. 著录符号和标点

| 符号 | 用在哪 |
|---|---|
| `. ` | 题名、其他责任者、版本、出版项、刊名、获取路径、DOI 之前；每条末尾 |
| `: ` | 其他题名信息（副题名）、出版者、页码、标准号/专利号/报告编号之前 |
| `, ` | 著者之间、「等」「译」之前、出版年、期刊年和卷之间 |
| `; ` | 同一著者的合订题名之间；期刊连载的后续年卷期之前 |
| `//` | 析出文献的出处之前（书中章节、论文集中论文） |
| `( )` | 期号、报纸版次、电子资源更新日期、非公元纪年 |
| `[ ]` | 序号、类型标识、引用日期、自拟信息（[出版地不详]） |
| `/` | 合期号 `(5/6)`、载体标识前 `[J/OL]` |
| `-` | 起讫页码、起讫序号 |

默认半角符号后空一格（英文文献必须半角）。全角半角混用、少空格、多空格都改。题名里本来就有的标点不动，只把副题名前的冒号统一。

## 5. 各类型的著录格式

下面是顺序编码制格式（精简版只出顺序编码制）。`[ ]` 括起的项目缺了就不写。

**图书 [M]**：著者. 题名: 其他题名信息[M]. 其他责任者. 版本. 出版地: 出版者, 出版年: 引文页码[引用日期]. 获取和访问路径. DOI.
- `[1] 陈登原. 国史旧闻: 第1卷[M]. 北京: 中华书局, 2000: 29.`
- `[2] 库恩. 科学革命的结构: 第4版[M]. 金吾伦, 胡新和, 译. 2版. 北京: 北京大学出版社, 2012.`
- `[3] CRAWFPRD W, GORMAN M. Future libraries: dreams, maddness, & reality[M]. Chicago: American Library Association, 1995.`（2015 示例原样，姓全大写）
- 版本：第 1 版不写；「第2版」写「2版」；英文 `2nd ed.`。

**图书中的析出文献 [M]**：析出著者. 析出题名[M]//图书著者. 图书题名. 版本. 出版地: 出版者, 出版年: 析出页码.
- `[4] 白书农. 植物开花研究[M]//李承森. 植物科学进展. 北京: 高等教育出版社, 1998: 146-163.`

**期刊论文 [J]**：著者. 题名[J]. 刊名, 年, 卷(期): 起止页码. DOI.
- `[5] 袁训来, 陈哲, 肖书海, 等. 蓝田生物群: 一个认识多细胞生物起源和早期演化的新窗口[J]. 科学通报, 2012, 55(34): 3219-3227.`
- 无卷号：`杨洪升. 四库馆私家抄校书考略[J]. 文献, 2013(1): 56-75.`
- 无期号：`Nature, 1992, 359: 605-609.`；合期：`2006, 57(5/6): 169-176.`
- 无页码只有文章编号：文章编号当页码写 `2023, 12: giad067`。
- 在线：2015 `[J/OL]. 图书情报工作, 2008, 52(6): 6-12[2013-10-25]. http://... .`；2025 不写引用日期。

**报纸 [N]**：著者. 题名[N]. 报纸名, 出版日期(版次).
- `[6] 丁文祥. 数字革命与竞争国际化[N]. 中国青年报, 2000-11-20(15).`

**学位论文 [D]**：著者. 题名[D]. 授予单位所在地: 授予单位, 年份: 引文页码.
- `[7] 吴云芳. 面向中文信息处理的现代汉语并列结构研究[D]. 北京: 北京大学, 2003.`
- 2025：`王琦. 融合星载 GNSS-R 和 SAR 数据的高时空分辨率土壤湿度反演方法研究[D]. 武汉: 武汉大学, 2022: 87.`
- 只写「北京大学, 2003」缺所在地：补城市名（北京大学→北京），补了要请买家核对。

**会议论文 [C]**：著者. 题名[C]//论文集编者. 论文集名. 出版地: 出版者, 出版年: 页码.
- `[8] 汪学军. 中国农业转基因生物研发进展与安全管理[C]//国家环境保护总局生物安全管理办公室. 中国国家生物安全框架实施国际合作项目研讨会论文集. 北京: 中国环境科学出版社, 2002: 22-25.`
- 2025 未正式出版的会议录：`李妍, 王莹. 医疗机构保洁人员“一前五后”手卫生干预效果研究[C]//中华预防医学会医院感染控制分会第31次全国医院感染学术年会, 2022: 2.`

**报告 [R]**：2015 `著者. 题名: 报告编号[R]. 出版地: 出版者, 年: 页码.`；2025 `著者. 题名: 报告编号[R]. 发布日期: 页码.`
- `World Health Organization. Factors regulating the immune response: report of WHO Scientific Group[R]. Geneva: WHO, 1970.`

**标准 [S]**：
- 2015：`信息与文献 参考文献著录规则: GB/T 7714—2015[S]. 北京: 中国标准出版社, 2015: 15.`（多数学校只要「题名: 标准号[S]」）
- 2025：`GB/T 3792—2021 信息与文献 资源描述[S].`

**专利 [P]**：
- 2015：`邓一刚. 全智能节电器: 200610171314.3[P]. 2006-12-13.`
- 2025：`邓一刚. 全智能节电器: CN200610171314.3[P]. 2008-01-16: 8-9.`

**网页 [EB/OL]**：著者. 题名[EB/OL]. (更新日期)[引用日期]. 网址.
- `李强. 化解医患矛盾需釜底抽薪[EB/OL]. (2012-05-03)[2013-03-25]. http://wenku.baidu.com.`

**数据集 [DS/OL]（2025）**：著者. 题名[DS/OL]. 版本. 发布平台(发布或修改日期)[引用日期]. 网址. 永久标识符.

**预印本 [PP/OL]（2025）**：著者. 题名[PP/OL]. 版本. 出版平台(创建或修改日期)[引用日期]. 网址. 永久标识符.
- `肖玲, 张雪, 王永. 数据要素的统计测算方法探究[PP/OL]. PSSXiv(2024-07-02)[2024-09-30]. https://zsyyb.cn/abs/202408.01096. CSTR: 32012.36.PSSXiv.202408.01096.`

**APA、MLA 等英文格式转国标**：作者改姓在前、名缩写不加点；`&` 去掉；年份从作者后挪到刊名后（顺序编码制）；加类型标识；`Journal, 12(3), 45–67` 改 `Journal, 年, 12(3): 45-67`；APA 7 的图书没有出版地，国标要出版地 → 列进待补，不要凭印象写 New York。

## 6. 必备项：缺了要买家补的

只有买家（或原文）知道的信息，缺了一律列进「待补」，在改好的列表里该条末尾标【待补：xx】，**不估、不编、不从记忆里补**：

| 类型 | 缺了要补 |
|---|---|
| 期刊 [J] | 刊名、年、卷或期（至少一项）、起止页码或文章编号 |
| 图书 [M]、学位论文 [D]、报告 [R] | 出版地、出版者（授予单位）、出版年 |
| 网络版报告 [R/OL] | 发布日期（如 `(2013-04-16)`）或「出版地: 出版者, 年」至少一样；2015 版还要引用日期 |
| 会议论文 [C] | 论文集名、出版地、出版者、出版年、页码（2025 未正式出版的会议录：会议名称、年份、页码）；论文集名里的学会、单位不能当出版者填 |
| 析出文献 `//` | 所在书或论文集的题名、析出页码 |
| 报纸 [N] | 出版日期、版次 |
| 专利 [P] | 专利号、公告日期 |
| 标准 [S] | 标准编号 |
| 网络资源 /OL | 网址；引用日期（买家访问的那天，2015 所有 /OL、2025 只 EB/DS/PP） |
| 学校要求 DOI 时 | DOI（期刊官网、知网文章页照抄） |

可以补但要请买家核对的：出版地能由知名出版社或大学推出（科学出版社→北京、浙江大学→杭州），补上并注明「据出版者所在地补，请核对」。查不到写 `[出版地不详]`（西文 `[S.l.]`），出版者不详写 `[出版者不详]`（`[s.n.]`）。

## 7. 日期、页码、DOI

- 日期一律 `YYYY-MM-DD`：`2013-3-6`、`2013年3月6日`、`2013/03/06` → `2013-03-06`。引用日期晚于今天、早于发布日期，都是错的，请买家核对。
- 页码：起讫用「-」，去掉 `pp.` `p.` `第…页`；`~` `—` `–` 统一成 `-`；止页简写 `1234-56` 补全成 `1234-1256`；起页大于止页请核对。
- DOI：写成 `DOI: 10.xxxx/xxxx`，放在网址之后、条目最末；`doi:`、`https://doi.org/10…` 都改成这个写法。DOI 必须以 `10.` 加 4~9 位数字和 `/` 开头，不像的请核对原文。2025 版网址里已含 DOI 时可不再写。学校不要求时缺 DOI 不算错。

## 8. 手工校对顺序（没有脚本时）

每条按这个顺序过一遍，前一步定了后一步才有意义：

1. 判类型：有没有类型标识、对不对；没有就看结构（`刊名, 年, 卷(期): 页` 是期刊；`出版地: 出版社, 年` 是图书；授予单位是大学的是学位论文；`//` 是析出）。看不出就问。
2. 著者：人数、等/et al.、姓名顺序、大小写、分隔符。
3. 题名和副题名冒号。
4. 出处：按第 5 节该类型的格式逐项对，缺的进待补。
5. 页码、日期、DOI 的写法。
6. 标点和空格统一。
7. 全部条目过完，再查重复条目（题名相同的两条）。

交付三块：改好的列表（缺项处标【待补：xx】）→ 待补和待核对清单 → 逐条改动说明（原文 → 改为 → 改了什么、依据哪条）。
