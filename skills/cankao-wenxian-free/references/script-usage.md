# 脚本用法

## 最小依赖

Python 3.8 及以上，只用标准库，不联网、不上传、不写文件，结果打印在屏幕上。输入读 .txt / .md（UTF-8、GBK、UTF-16 自动识别）或标准输入。

## 命令

```bash
python3 scripts/gb7714.py fix <列表.txt 或 -> [参数]       # 逐条改成指定版本（默认 2025）
python3 scripts/gb7714.py upgrade <列表.txt 或 -> [参数]   # 2015 版列表转 2025 版，判 6 处差异
python3 scripts/gb7714.py -h                               # 看参数
python3 -m unittest discover -s tests                      # 自检
```

## 参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--edition 2015\|2025` | 2025 | fix 模式改成哪一版；upgrade 固定输出 2025 |
| `--max-authors N` | 3 | 著者列几位后加「等 / et al.」，1~50 |
| `--no-etal-comma` | 关 | 「等 / et al.」前不加逗号 |
| `--punct half\|mixed\|tight` | half | 半角加空格 / 中文逗号冒号括号全角（照 2025 原文排版）/ 半角不空格 |
| `--cite-date YYYY-MM-DD` | 无 | 网络资源缺引用日期时统一补这天 |
| `--require-doi` | 关 | 期刊论文缺 DOI 列进待补 |

## 输出各段

| 段 | 意思 |
|---|---|
| 依据 / 学校另有模板以学校为准 / 共几条 | 结论，照写进回答第一段 |
| 2015 → 2025：6 处规则差异命中情况 | upgrade 才有：命中几处、哪几处、各在哪几条 |
| 改好的列表 | 拿来就能贴；缺项处标【待补：xx】 |
| 要你补 | 原文缺的信息，买家照原文补 |
| 要你核对 | 脚本推断的（类型、出版地）或可疑的（日期、DOI、页码倒置、重复） |
| 要你定 | 国标留了余地或要看学校规定 |
| 逐条改了什么 | 原文 → 改为 → 每处改动的原因 |
